# freeCodeCamp format samples (reference only)

Fetched 2026-10-08 from github.com/freeCodeCamp/freeCodeCamp (BSD-3-Clause curriculum). Use them to understand
the section style and test-writing style. Never copy their prose into our content; our format is defined in
docs/content-format.md and differs in places.

| File | What it shows |
|---|---|
| workshop-step-1.md, -3.md, -21.md | Workshop steps: short description, ordered tests with diagnostic messages, seed with editable region |
| python-workshop-step.md | Python step tests (fCC runs them in Pyodide) |
| lab-recipe-page.md | Lab: user stories, full test list, solution |
| lecture.md | Lecture: interactive editor snippets + 3 questions with per-option feedback |
| review.md | Review page |
| quiz-excerpt.md | Quiz question format (first 120 lines) |
