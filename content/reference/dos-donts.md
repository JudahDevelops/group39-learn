# Do's and Don'ts

| Do | Don't |
|---|---|
| Collaborate equitably across all group members | Write code before the architecture is complete |
| Base the system architecture on verified literature | Copy another group's project or existing code |
| Propose realistic, measurable improvements | Fabricate papers or let AI invent references |
| Cite verified academic sources in APA 7 | Draw architecture diagrams you can't explain |
| Make sure every member understands and can defend every diagram | Choose a tech stack just because it's popular |

*Zero tolerance: plagiarism or unverified AI fabrications result in immediate project failure.*
