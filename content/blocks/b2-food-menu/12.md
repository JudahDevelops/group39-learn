# --description--

`padding` is the space between the content and the border. Inside the `.menu` rule, add a `padding` declaration set to `1.5rem`.

# --hints--

Your `.menu` should have a `padding` of `1.5rem` on all four sides.

```js
const cs = getComputedStyle(document.querySelector('.menu'));
['Top', 'Right', 'Bottom', 'Left'].forEach((side) => assert.equal(cs['padding' + side], '24px'));
```

# --help--

## --hint--

Padding sits inside the border and pushes the content away from it. Margin sits outside the border.

## --hint--

One value on `padding` is used for all four sides. `rem` is the unit.

## --hint--

Type `padding: 1.5rem;` on the empty line inside the `.menu` rule.
