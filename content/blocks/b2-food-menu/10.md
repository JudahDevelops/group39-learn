# --description--

Every element is a box with content, padding, a border and a margin. By default, a box's `width` leaves out its padding and border, which makes sizes hard to work out. Fix that for every element. Below the `:root` rule, add a rule with the selector `*`, which matches everything, and set `box-sizing` to `border-box`.

# --hints--

Your `styles.css` should have a rule with the selector `*`.

```js
assert.match(files['styles.css'], /(?:^|[}\s])\*\s*\{/);
```

Every element on your page should have a `box-sizing` of `border-box`. Use the `*` selector, so that it matches all of them.

```js
const els = [document.body, ...document.body.querySelectorAll('*')];
els.forEach((el) => assert.equal(getComputedStyle(el).boxSizing, 'border-box'));
```

# --help--

## --hint--

The selector `*` is a wildcard. A rule with it applies to every element on the page.

## --hint--

The property is `box-sizing` and the value is `border-box`. Write the hyphen in both.

## --hint--

Type `* {` on the first line, `box-sizing: border-box;` on the next, and `}` below it.
