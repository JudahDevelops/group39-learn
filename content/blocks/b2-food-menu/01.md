# --description--

In this workshop you will style a menu for the student cafeteria. The page, `menu.html`, is already written. The styles go in `styles.css`, which is empty for now.

First, connect the two. In the `head`, below the `title`, add a `link` element with `rel` set to `stylesheet` and `href` set to `styles.css`.

# --hints--

Your `head` element should have a `link` element.

```js
assert.match(code, /<head[\s>][\s\S]*<link[\s>][\s\S]*<\/head\s*>/i);
```

Your `link` element should have the attribute `rel="stylesheet"`. Put the value in quotation marks inside the tag.

```js
assert.match(code, /<link\s[^>]*rel\s*=\s*("|')stylesheet\1[^>]*>/i);
```

Your `link` element should have the attribute `href="styles.css"`. Check the spelling of the file name.

```js
assert.match(code, /<link\s[^>]*href\s*=\s*("|')(?:\.\/)?styles\.css\1[^>]*>/i);
```

A `link` element has no closing tag. Remove any `</link>`.

```js
assert.notMatch(code, /<\/link\s*>/i);
```

# --help--

## --hint--

A `link` element connects the page to another file. Like `meta`, it is one tag with attributes and has no closing tag.

## --hint--

Write `<link`, then the attribute `rel="stylesheet"`, then the attribute `href="styles.css"`, then `>`.

## --hint--

Type `<link rel="stylesheet" href="styles.css">` on the empty line.
