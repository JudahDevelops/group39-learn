# --description--

Separate the dishes. Inside the `.dish` rule, add `padding` set to `0.75rem`, and `border-bottom` set to `1px solid var(--muted)`. `border-bottom` draws a border on the bottom side only.

# --hints--

Every `.dish` should have a `padding` of `0.75rem` on all four sides.

```js
document.querySelectorAll('.dish').forEach((d) => {
  const cs = getComputedStyle(d);
  ['Top', 'Right', 'Bottom', 'Left'].forEach((side) => assert.equal(cs['padding' + side], '12px'));
});
```

Every `.dish` should have a bottom border that is `1px` wide and `solid`.

```js
document.querySelectorAll('.dish').forEach((d) => {
  const cs = getComputedStyle(d);
  assert.equal(cs.borderBottomWidth, '1px');
  assert.equal(cs.borderBottomStyle, 'solid');
});
```

The bottom border of every `.dish` should have the colour `#5b6b80`. Use the variable: `var(--muted)`.

```js
document.querySelectorAll('.dish').forEach((d) => assert.equal(getComputedStyle(d).borderBottomColor, 'rgb(91, 107, 128)'));
```

# --help--

## --hint--

There are two declarations to add. One makes space inside each dish, and one draws a line under it.

## --hint--

`border-bottom` takes the same three values as `border`: width, style and colour.

## --hint--

Type `padding: 0.75rem;` on one line and `border-bottom: 1px solid var(--muted);` on the next, inside the `.dish` rule.
