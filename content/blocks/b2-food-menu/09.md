# --description--

A **class** gives an element a name that CSS can use. Add the attribute `class="menu"` to the opening tag of the `main` element. You will turn the menu into a card next.

# --hints--

Your `main` element should have the attribute `class="menu"`. Put the value in quotation marks inside the opening tag.

```js
assert.isTrue(document.querySelector('main')?.classList.contains('menu'));
```

Your `main` element should still hold the headings and the four dishes. Change only its opening tag.

```js
assert.lengthOf(document.querySelectorAll('main > h2'), 2);
assert.lengthOf(document.querySelectorAll('main > .dish'), 4);
```

# --help--

## --hint--

An attribute goes inside the opening tag, after the element name. The `main` element keeps its closing tag as it is.

## --hint--

The attribute is written `class="name"`. The name you need is `menu`.

## --hint--

Change the line to `<main class="menu">`.
