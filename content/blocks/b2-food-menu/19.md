# --description--

An element can have more than one class, separated by spaces. Today's special is the egusi soup. Change the `class` attribute on its `div` to `dish special`.

# --hints--

The `div` for the egusi soup should have both classes, `dish` and `special`. Put them in one `class` attribute, separated by a space.

```js
const dish = [...document.querySelectorAll('.dish')].find((d) => d.textContent.includes('Egusi soup'));
assert.exists(dish);
assert.isTrue(dish.classList.contains('special'));
```

Only the egusi soup should be the special. The other dishes should not have the class `special`.

```js
assert.lengthOf(document.querySelectorAll('.special'), 1);
```

Your four dishes should keep the class `dish`.

```js
assert.lengthOf(document.querySelectorAll('.dish'), 4);
```
