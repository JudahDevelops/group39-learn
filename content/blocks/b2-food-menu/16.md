# --description--

Push the name and the price to opposite ends of the row. Inside the `.dish` rule, add `justify-content` set to `space-between`. It spreads the items along the row and puts all the free space between them.

# --hints--

Every `.dish` should have a `justify-content` of `space-between`.

```js
document.querySelectorAll('.dish').forEach((d) => assert.equal(getComputedStyle(d).justifyContent, 'space-between'));
```

The price in each dish should sit at the right end of the row.

```js
document.querySelectorAll('.dish').forEach((d) => {
  const price = d.querySelector('.price').getBoundingClientRect();
  assert.approximately(price.right, d.getBoundingClientRect().right, 2);
});
```

# --help--

## --hint--

`justify-content` controls how the items share out the space along the row. It only works on an element with `display: flex`.

## --hint--

The value you need is made of two words joined by a hyphen: `space` and `between`.

## --hint--

Type `justify-content: space-between;` on the empty line inside the `.dish` rule.
