# --description--

Soften the paragraphs. Add a rule for `p` with two declarations: `color` set to `var(--muted)`, and `line-height` set to `1.5`. `line-height` is the space between lines of text, as a multiple of the font size.

# --hints--

Your `styles.css` should have a rule for `p`.

```js
assert.match(files['styles.css'], /(?:^|[}\s,])p\s*\{/);
```

Your `p` elements should have a `color` of `#5b6b80`.

```js
const ps = document.querySelectorAll('p');
assert.isAbove(ps.length, 0);
ps.forEach((p) => assert.equal(getComputedStyle(p).color, 'rgb(91, 107, 128)'));
```

Your `p` rule should use the variable: `color: var(--muted);`.

```js
assert.match(files['styles.css'], /(?:^|[;{\s])color\s*:\s*var\(\s*--muted\s*\)/);
```

Your `p` elements should have a `line-height` of `1.5`. Write the number with no unit.

```js
document.querySelectorAll('p').forEach((p) => {
  const cs = getComputedStyle(p);
  assert.approximately(parseFloat(cs.lineHeight) / parseFloat(cs.fontSize), 1.5, 0.01);
});
```

# --help--

## --hint--

The selector `p` matches every paragraph on the page. Put both declarations between the braces, each ending with a semicolon.

## --hint--

The first declaration is `color: var(--muted);`. The second sets `line-height` to a plain number.

## --hint--

Type `p {`, then `color: var(--muted);` and `line-height: 1.5;` on two lines, then `}`.
