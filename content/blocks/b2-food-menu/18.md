# --description--

Make the prices stand out. Add a `.price` rule that sets `color` to `var(--accent)` and `font-size` to `1.1rem`. A `rem` is the browser's base text size, so `1.1rem` is a little larger than normal.

# --hints--

Your `styles.css` should have a rule for `.price`.

```js
assert.match(files['styles.css'], /\.price\s*\{/);
```

Every `.price` should have a `color` of `#9a3b12`. Use the variable: `var(--accent)`.

```js
const prices = document.querySelectorAll('.price');
assert.lengthOf(prices, 4);
prices.forEach((p) => assert.equal(getComputedStyle(p).color, 'rgb(154, 59, 18)'));
```

Every `.price` should have a `font-size` of `1.1rem`.

```js
document.querySelectorAll('.price').forEach((p) => assert.approximately(parseFloat(getComputedStyle(p).fontSize), 17.6, 0.05));
```

:root {
  --text: #1a1a1a;
  --accent: #9a3b12;
  --muted: #5b6b80;
  --paper: #fff8ee;
}

* {
  box-sizing: border-box;
}

body {
  font-family: system-ui, sans-serif;
  color: var(--text);
  background-color: var(--paper);
}

  color: var(--accent);
}

h1 {
  text-align: center;
}

p {
  color: var(--muted);
  line-height: 1.5;
}

  max-width: 36rem;
  margin: 0 auto;

}

  display: flex;
  justify-content: space-between;
  padding: 0.75rem;
  border-bottom: 1px solid var(--muted);

# --help--

## --hint--

The class is `price`, so the selector is `.price`. This rule has two declarations.

## --hint--

Colours use `color` and a variable. Sizes use `font-size` and a number with the unit `rem`.

## --hint--

Type `.price {`, then `color: var(--accent);` and `font-size: 1.1rem;` on two lines, then `}`.
