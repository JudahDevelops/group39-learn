# --description--

Round the corners. Inside the `.menu` rule, add a `border-radius` declaration set to `8px`.

# --hints--

Your `.menu` should have a `border-radius` of `8px` on all four corners.

```js
const cs = getComputedStyle(document.querySelector('.menu'));
['TopLeft', 'TopRight', 'BottomRight', 'BottomLeft'].forEach((corner) => assert.equal(cs['border' + corner + 'Radius'], '8px'));
```

# --help--

## --hint--

A larger radius makes a rounder corner. The corners are cut from the border, so the border must already be there.

## --hint--

The property name has two hyphens: `border`, a hyphen, `radius`.

## --hint--

Type `border-radius: 8px;` on the empty line inside the `.menu` rule.
