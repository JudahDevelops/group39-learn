# --description--

A variable names a value once, so you can reuse it. Variables go in a rule with the selector `:root`, and their names start with two hyphens. At the top of `styles.css`, add a `:root` rule with four variables: `--text` set to `#1a1a1a`, `--accent` set to `#9a3b12`, `--muted` set to `#5b6b80` and `--paper` set to `#fff8ee`.

# --hints--

Your `styles.css` should have a rule for `:root`. It starts with `:root {` and ends with `}`.

```js
assert.match(files['styles.css'], /:root\s*\{[\s\S]*?\}/);
```

Your `:root` rule should have a `--text` variable set to `#1a1a1a`.

```js
const v = getComputedStyle(document.documentElement).getPropertyValue('--text').trim().toLowerCase();
assert.equal(v, '#1a1a1a');
```

Your `:root` rule should have an `--accent` variable set to `#9a3b12`.

```js

assert.equal(v, '#9a3b12');
```

Your `:root` rule should have a `--muted` variable set to `#5b6b80`.

```js
const v = getComputedStyle(document.documentElement).getPropertyValue('--muted').trim().toLowerCase();
```

# --help--

## --hint--

A variable is a declaration whose property name starts with two hyphens. The value is the colour. The `:root` rule stands for the whole page.

## --hint--

Write `:root {`, then one declaration for each variable, such as `--text: #1a1a1a;`, then `}`. Each declaration ends with a semicolon.

## --hint--

Type `:root {`, then the four lines `--text: #1a1a1a;`, `--accent: #9a3b12;`, `--muted: #5b6b80;` and `--paper: #fff8ee;`, then `}`.
