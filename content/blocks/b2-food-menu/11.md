# --description--

Now shape the menu into a card. A dot in a selector means a class, so `.menu` matches the `main` element you just named. Add a `.menu` rule with `max-width` set to `36rem`, so that the card stops growing on a wide screen, and `margin` set to `0 auto`, which keeps the top and bottom margins at zero and centres the card.

# --hints--

Your `styles.css` should have a rule for `.menu`. The class selector starts with a dot.

```js
assert.match(files['styles.css'], /\.menu\s*\{/);
```

Your `.menu` should have a `max-width` of `36rem`.

```js
assert.equal(getComputedStyle(document.querySelector('.menu')).maxWidth, '576px');
```

Your `.menu` should be centred. Set `margin` to `0 auto`, so that the left and right margins are equal.

```js
const cs = getComputedStyle(document.querySelector('.menu'));
assert.isAbove(parseFloat(cs.marginLeft), 0);
assert.equal(cs.marginLeft, cs.marginRight);
```

Your `.menu` should have no margin above or below it. Set `margin` to `0 auto`, where `0` is the top and bottom.

```js
const cs = getComputedStyle(document.querySelector('.menu'));
assert.equal(cs.marginTop, '0px');
assert.equal(cs.marginBottom, '0px');
```

# --help--

## --hint--

The selector is the class name with a dot in front. The two declarations go between the braces.

## --hint--

`margin` can take two values: the first is for the top and bottom, the second for the left and right. `auto` on the sides centres a box that has a width limit.

## --hint--

Type `.menu {`, then `max-width: 36rem;` and `margin: 0 auto;` on two lines, then `}`.
