# --description--

A comma lets one rule style several selectors. Below the `body` rule, add a rule for `h1, h2` that sets `color` to `var(--accent)`.

# --hints--

Your `styles.css` should have a rule for `h1, h2`.

```js
assert.match(files['styles.css'], /\bh1\s*,\s*h2\s*\{/);
```

Your `h1` should have a `color` of `#9a3b12`.

```js
assert.equal(getComputedStyle(document.querySelector('h1')).color, 'rgb(154, 59, 18)');
```

Your `h2` elements should have a `color` of `#9a3b12`. Check that the selector lists both elements, with a comma between them.

```js
const h2s = document.querySelectorAll('h2');
assert.isAbove(h2s.length, 0);
h2s.forEach((h) => assert.equal(getComputedStyle(h).color, 'rgb(154, 59, 18)'));
```

Your `h1, h2` rule should use the variable: `color: var(--accent);`.

```js
assert.match(files['styles.css'], /(?:^|[;{\s])color\s*:\s*var\(\s*--accent\s*\)/);
```

# --help--

## --hint--

To style two kinds of element with the same declarations, write both selectors before the opening brace, separated by a comma.

## --hint--

The selector is `h1, h2`. Inside the braces, use `color` with `var(--accent)`.

## --hint--

Type `h1, h2 {` on the first line, `color: var(--accent);` on the next, and `}` below it.
