# --description--

Most students will open this menu on a phone. A **media query** applies its rules only when its condition is true. At the end of `styles.css`, add `@media (max-width: 600px)`, which means a screen 600px wide or less. Inside its braces, add a `.menu` rule that sets `padding` to `0.75rem`.

# --hints--

Your `styles.css` should have a media query that starts with `@media (max-width: 600px)`.

```js
const media = [...document.styleSheets].flatMap((s) => [...s.cssRules]).filter((r) => r instanceof CSSMediaRule);
assert.isTrue(media.some((r) => /max-width:\s*600px/.test(r.media.mediaText)));
```

Your media query should have a rule for `.menu` inside its curly braces.

```js
const media = [...document.styleSheets].flatMap((s) => [...s.cssRules]).filter((r) => r instanceof CSSMediaRule && /max-width:\s*600px/.test(r.media.mediaText));
assert.isTrue(media.some((r) => [...r.cssRules].some((c) => c.selectorText === '.menu')));
```

The `.menu` rule inside your media query should set `padding` to `0.75rem`.

```js
const media = [...document.styleSheets].flatMap((s) => [...s.cssRules]).filter((r) => r instanceof CSSMediaRule && /max-width:\s*600px/.test(r.media.mediaText));
const rule = media.flatMap((r) => [...r.cssRules]).find((c) => c.selectorText === '.menu');
assert.exists(rule);
assert.equal(rule.style.paddingTop, '0.75rem');
```

Your original `.menu` rule should keep its `padding` of `1.5rem` on a wide screen. Check that your new rule is inside the media query, not outside it.

```js
assert.equal(getComputedStyle(document.querySelector('.menu')).paddingTop, '24px');
```

# --help--

## --hint--

A media query wraps other rules in its own curly braces. The condition goes in brackets after `@media`.

## --hint--

The structure is `@media (max-width: 600px) {`, then a full `.menu` rule, then a closing `}` for the media query.

## --hint--

Type `@media (max-width: 600px) {`, then `.menu {`, then `padding: 0.75rem;`, then `}` to close `.menu`, then `}` to close the media query.
