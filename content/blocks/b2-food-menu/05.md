# --description--

Give the page a warm background. Inside the `body` rule, below `color`, add a `background-color` declaration set to `var(--paper)`.

# --hints--

Your `body` should have a `background-color` of `#fff8ee`.

```js
assert.equal(getComputedStyle(document.body).backgroundColor, 'rgb(255, 248, 238)');
```

Your `body` rule should use the variable: `background-color: var(--paper);`.

```js
assert.match(files['styles.css'], /background-color\s*:\s*var\(\s*--paper\s*\)/);
```

# --help--

## --hint--

The property for the colour behind an element is `background-color`. Do not mix it up with `color`, which is the text.

## --hint--

Use the same pattern as the last step: the property, a colon, `var()` with the variable name inside, and a semicolon.

## --hint--

Type `background-color: var(--paper);` on the empty line inside the `body` rule.
