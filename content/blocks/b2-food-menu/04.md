# --description--

Use a variable with `var()`. Inside the `body` rule, below `font-family`, add a `color` declaration set to `var(--text)`. `color` is the colour of the text.

# --hints--

Your `body` should have a `color` of `#1a1a1a`.

```js
assert.equal(getComputedStyle(document.body).color, 'rgb(26, 26, 26)');
```

Your `body` rule should use the variable, not the colour itself: `color: var(--text);`.

```js
assert.match(files['styles.css'], /(?:^|[;{\s])color\s*:\s*var\(\s*--text\s*\)/);
```

# --help--

## --hint--

`var()` reads a variable. The name of the variable goes inside the brackets, with its two hyphens.

## --hint--

The declaration is `color`, a colon, `var(--text)` and a semicolon. It goes between the curly braces of the `body` rule.

## --hint--

Type `color: var(--text);` on the empty line inside the `body` rule.
