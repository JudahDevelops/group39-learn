# --description--

Highlight the special. Two classes joined with no space make a selector that matches elements with both. Add a `.dish.special` rule that sets `background-color` to `#fde8cf`.

# --hints--

Your `styles.css` should have a rule with the selector `.dish.special`. Write the two class names with no space between them.

```js
assert.match(files['styles.css'], /\.dish\.special\s*\{/);
```

The egusi soup should have a `background-color` of `#fde8cf`.

```js
const dish = [...document.querySelectorAll('.dish')].find((d) => d.textContent.includes('Egusi soup'));
assert.equal(getComputedStyle(dish).backgroundColor, 'rgb(253, 232, 207)');
```

Only the special should have the new background. The other dishes should stay without one.

```js
document.querySelectorAll('.dish:not(.special)').forEach((d) => assert.equal(getComputedStyle(d).backgroundColor, 'rgba(0, 0, 0, 0)'));
```

# --help--

## --hint--

A space in a selector means something different: `.dish .special` would look for a `special` element inside a `dish`. No space means one element with both classes.

## --hint--

The selector is a dot, `dish`, a second dot, and `special`, all joined together.

## --hint--

Type `.dish.special {` on the first line, `background-color: #fde8cf;` on the next, and `}` below it.
