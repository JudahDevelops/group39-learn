# --description--

A CSS rule has a selector, then curly braces with declarations inside. Write your first rule. Its selector is `body`, and it has one declaration: `font-family` set to `system-ui, sans-serif`. The text of the whole page will use that font.

# --hints--

Your `styles.css` should have a rule for `body`. It starts with `body {` and ends with `}`.

```js
assert.match(files['styles.css'], /\bbody\s*\{[\s\S]*\}/);
```

Your `body` should have a `font-family` of `system-ui, sans-serif`. Check the spelling, put a comma between the two names, and end the declaration with a semicolon.

```js
const family = getComputedStyle(document.body).fontFamily;
assert.include(family, 'system-ui');
assert.include(family, 'sans-serif');
```

# --help--

## --hint--

A rule starts with the selector, which is the name of the element to style. The declarations go between curly braces.

## --hint--

A declaration is a property, a colon, a value and a semicolon. The property here is `font-family`.

## --hint--

Type `body {` on the first line, `font-family: system-ui, sans-serif;` on the next, and `}` below it.
