# --description--

`text-align` sets how text lines up inside its box. Below the `h1, h2` rule, add a rule for `h1` alone that sets `text-align` to `center`. The `h2` headings stay on the left.

# --hints--

Your `h1` should have a `text-align` of `center`.

```js
assert.equal(getComputedStyle(document.querySelector('h1')).textAlign, 'center');
```

Only the `h1` should be centred. Your `h2` elements should keep their `text-align`. Check that your rule has the selector `h1`, not `h1, h2`.

```js
document.querySelectorAll('h2').forEach((h) => assert.notEqual(getComputedStyle(h).textAlign, 'center'));
```

# --help--

## --hint--

A rule with the selector `h1` styles only the `h1` element. A second rule for the same element is fine.

## --hint--

The property is `text-align` and the value is `center`. Spell centre the American way.

## --hint--

Type `h1 {` on the first line, `text-align: center;` on the next, and `}` below it.
