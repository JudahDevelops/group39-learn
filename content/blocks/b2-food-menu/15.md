# --description--

Each dish is a `div` with the class `dish`. It holds a `span` for the name and a `span` for the price. A `span` is a plain piece of text inside a line. Add a `.dish` rule with `display` set to `flex`, which lines up the children of an element in a row.

# --hints--

Your `styles.css` should have a rule for `.dish`.

```js
assert.match(files['styles.css'], /\.dish\s*\{/);
```

Every `.dish` should have a `display` of `flex`.

```js
const dishes = document.querySelectorAll('.dish');
assert.lengthOf(dishes, 4);
dishes.forEach((d) => assert.equal(getComputedStyle(d).display, 'flex'));
```

# --help--

## --hint--

Flexbox works on a container. The element you style is the parent, and its children become the items in the row.

## --hint--

The property is `display` and the value is the word `flex`.

## --hint--

Type `.dish {` on the first line, `display: flex;` on the next, and `}` below it.
