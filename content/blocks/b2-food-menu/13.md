# --description--

A border is a line around the padding. Inside the `.menu` rule, add a `border` declaration with three values in order: the width `1px`, the style `solid` and the colour `var(--accent)`.

# --hints--

Your `.menu` should have a border that is `1px` wide on all four sides.

```js
const cs = getComputedStyle(document.querySelector('.menu'));
['Top', 'Right', 'Bottom', 'Left'].forEach((side) => assert.equal(cs['border' + side + 'Width'], '1px'));
```

Your `.menu` border should have the style `solid`.

```js
assert.equal(getComputedStyle(document.querySelector('.menu')).borderTopStyle, 'solid');
```

Your `.menu` border should have the colour `#9a3b12`. Use the variable: `var(--accent)`.

```js
assert.equal(getComputedStyle(document.querySelector('.menu')).borderTopColor, 'rgb(154, 59, 18)');
```

# --help--

## --hint--

`border` is a shorthand: one declaration that sets the width, the style and the colour of the line.

## --hint--

Write the three values after `border:`, separated by spaces: a width, a style word and a colour.

## --hint--

Type `border: 1px solid var(--accent);` on the empty line inside the `.menu` rule.
