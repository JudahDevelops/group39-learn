## HTML basics

A page is made of **elements**. Most elements have an opening tag, some content and a closing tag.

| Element | What it makes |
|---|---|
| `h1` | The main heading |
| `p` | A paragraph |
| `ul` and `li` | A bulleted list and its items |
| `button` | A button |

Try changing the text, then press Run.

::: tryit web
```html file=index.html
<h1>Hall Notice</h1>
<p>Water will be off on Friday.</p>
<button>Got it</button>
```
:::

### Remember

- Visible content goes inside `body`.
- A closing tag has a `/` in front of the name.
- Put the tags you want to show in backticks when you write about them.
