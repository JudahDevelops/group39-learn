# --description--

The IHMS has four kinds of user. Add a column called `role` after `password_hash`. It is text and it must have a value, with a `check` that allows only `'student'`, `'maintenance_officer'`, `'hall_warden'` and `'admin'`.

# --hints--

The `users` table should have the columns `id`, `full_name`, `email`, `password_hash` and `role`, in that order.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'users' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.column_name),
  ['id', 'full_name', 'email', 'password_hash', 'role'],
);
```

`role` should be `text`.

```js
const { rows } = await db.query(
```

`role` must have a value. Add `not null` after `text`.

