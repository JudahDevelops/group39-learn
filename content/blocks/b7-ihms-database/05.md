# --description--

Every room has a `number`, such as `A-101`. Add a column called `number` after `hostel_id`. It is text and it must have a value.

# --hints--

The `rooms` table should have the columns `id`, `hostel_id` and `number`, in that order.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'rooms' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.column_name),
  ['id', 'hostel_id', 'number'],
);
```

`number` should be `text`, because room numbers such as `A-101` contain a letter.

```js
const { rows } = await db.query(
  "select data_type from information_schema.columns where table_schema = 'public' and table_name = 'rooms' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.data_type),
  ['integer', 'integer', 'text'],
);
```

`number` must have a value. Add `not null` after `text`.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'rooms' and is_nullable = 'NO'",
);
assert.includeMembers(
  rows.map((r) => r.column_name),
  ['number'],
);
```
