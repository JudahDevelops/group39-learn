# --description--

In this workshop you write the IHMS database yourself, one table at a time. The finished design is on the <a href="/reference/schema" target="_blank" rel="noopener">Database schema</a> page. Press **See the finished project** to run the finished script and read what it builds.

Start with the hostels. Create a table called `hostels` with two columns. `id` is a whole number that PostgreSQL numbers for you, and it is the primary key. `name` is text that must have a value and that no two hostels share.

# --hints--

Your code should create a table called `hostels`.

```js
const { rows } = await db.query(
  "select table_name from information_schema.tables where table_schema = 'public' and table_name = 'hostels'",
);
assert.lengthOf(rows, 1);
```

The `hostels` table should have the columns `id` and `name`, in that order.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'hostels' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.column_name),
  ['id', 'name'],
);
```

`id` should be a whole number (`integer`) and `name` should be `text`.

```js
const { rows } = await db.query(
  "select data_type from information_schema.columns where table_schema = 'public' and table_name = 'hostels' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.data_type),
  ['integer', 'text'],
);
```

`id` should be the primary key. Add `primary key` after its type.

```js
const { rows } = await db.query(
  "select a.attname from pg_index i join pg_attribute a on a.attrelid = i.indrelid and a.attnum = any(i.indkey) where i.indrelid = 'hostels'::regclass and i.indisprimary",
);
assert.deepEqual(
  rows.map((r) => r.attname),
  ['id'],
);
```

PostgreSQL should number the rows for you. Write `generated always as identity` before `primary key`.

```js
const { rows } = await db.query(
  "select is_identity from information_schema.columns where table_schema = 'public' and table_name = 'hostels' and column_name = 'id'",
);
assert.equal(rows[0]?.is_identity, 'YES');
```

`name` must have a value. Add `not null` after `text`.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'hostels' and is_nullable = 'NO'",
);
assert.includeMembers(
  rows.map((r) => r.column_name),
  ['name'],
);
```

No two hostels should share a `name`. Add `unique` after `not null`.

```js
await db.query("insert into hostels (name) values ('Block X')");
let error;
try {
  await db.query("insert into hostels (name) values ('Block X')");
} catch (e) {
  error = e;
}
assert.exists(error);
assert.equal(error.code, '23505');
```

## --hint--

`create table` is followed by the table name, then the columns inside brackets, separated by commas.

## --hint--

Each column is its name, its type, then its rules. `id` has the rules `generated always as identity primary key`. `name` has the rules `not null unique`.
