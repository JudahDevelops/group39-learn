# --description--

A room has many bed spaces, so `bed_spaces` points to `rooms`. Create a table called `bed_spaces` with `id` (the usual primary key), `room_id` and `label`. `room_id` is a whole number that must have a value and must match a real room. `label` is text that must have a value, such as `1` or `2`.
