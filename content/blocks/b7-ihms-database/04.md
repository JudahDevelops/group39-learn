# --description--

A hostel has many rooms, so `rooms` points back to `hostels`. Create a table called `rooms` with `id` (the usual primary key) and `hostel_id`. `hostel_id` is a whole number that must have a value and must match a real hostel: `references hostels(id)`.

`hostel_id` must have a value. Add `not null` after `integer`.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'rooms' and is_nullable = 'NO'",
);
assert.includeMembers(
  rows.map((r) => r.column_name),
  ['hostel_id'],

```

`hostel_id` should point to a real hostel. Add `references hostels(id)` after `not null`.

```js
const { rows } = await db.query(
  "select a.attname as col, c.confrelid::regclass::text as ref from pg_constraint c join pg_attribute a on a.attrelid = c.conrelid and a.attnum = any(c.conkey) where c.conrelid = 'rooms'::regclass and c.contype = 'f' order by a.attnum",
);
assert.deepEqual(
  rows.map((r) => [r.col, r.ref]),
  [['hostel_id', 'hostels']],
);
```

A room in hostel 999 should be refused, because there is no such hostel.

```js
let error;
try {
  await db.query('insert into rooms (hostel_id) values (999)');
} catch (e) {
  error = e;
}
assert.exists(error);
assert.equal(error.code, '23503');
```

```sql file=query.sql
-- Hostel blocks.
create table hostels (
  id integer generated always as identity primary key,
  name text not null unique,
  gender text not null check (gender in ('male', 'female')),
  level integer not null
);

-- Rooms. Each room belongs to one hostel.
create table rooms (
  id integer generated always as identity primary key,
  hostel_id integer not null references hostels(id)
);
```

# --help--

## --hint--

`rooms` is built like `hostels`: an `id` column first, then the other columns.

## --hint--

`hostel_id integer not null references hostels(id)` says: a whole number, always present, that is the `id` of a row in `hostels`.
