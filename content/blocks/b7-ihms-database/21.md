# --description--

Every status change and every escalation is written down, so you can check later who was told what and when. One complaint has many history entries. Create a table called `complaint_history` with `id` (the usual primary key), `complaint_id` and `event`. `complaint_id` is a whole number that must have a value and must match a real complaint. `event` is text that must have a value.
