# --description--

A hostel is for men or for women. Add a column called `gender` after `name`. It is text and it must have a value. Add a `check` that allows only `'male'` and `'female'`.

# --hints--

The `hostels` table should have the columns `id`, `name` and `gender`, in that order.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'hostels' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.column_name),
  ['id', 'name', 'gender'],
);
```

`gender` should be `text`.

```js
const { rows } = await db.query(
  "select data_type from information_schema.columns where table_schema = 'public' and table_name = 'hostels' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.data_type),
  ['integer', 'text', 'text'],
);
```

`gender` must have a value. Add `not null` after `text`.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'hostels' and is_nullable = 'NO'",
);
assert.includeMembers(
  rows.map((r) => r.column_name),
  ['gender'],
);
```

A hostel with the gender `male` or `female` should be saved.

```js
await db.query("insert into hostels (name, gender) values ('Block M', 'male')");
await db.query("insert into hostels (name, gender) values ('Block F', 'female')");
```

A hostel with the gender `other` should be refused. Add `check (gender in ('male', 'female'))` after `not null`.

```js
let error;
try {
  await db.query("insert into hostels (name, gender) values ('Block O', 'other')");
} catch (e) {
  error = e;
}
assert.exists(error);
assert.equal(error.code, '23514');
```

# --help--

## --hint--

Put the new column in the same `create table` statement, after `name`. Remember the comma at the end of the `name` line.

## --hint--

A `check` is written in brackets after the column's other rules: `check (gender in ('male', 'female'))`. It lists the only values the column may hold.

## --hint--

Change the statement to:

```sql
create table hostels (
  id integer generated always as identity primary key,
  name text not null unique,
  gender text not null check (gender in ('male', 'female'))
);
```
