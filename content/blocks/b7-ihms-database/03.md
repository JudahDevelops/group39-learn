# --description--

Each hostel is for one level of students, such as 100 or 200. Add a column called `level` after `gender`. It is a whole number and it must have a value.

# --hints--

The `hostels` table should have the columns `id`, `name`, `gender` and `level`, in that order.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'hostels' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.column_name),
  ['id', 'name', 'gender', 'level'],
);
```

`level` should be a whole number (`integer`).

```js
const { rows } = await db.query(
  "select data_type from information_schema.columns where table_schema = 'public' and table_name = 'hostels' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.data_type),
  ['integer', 'text', 'text', 'integer'],
);
```

`level` must have a value. Add `not null` after `integer`.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'hostels' and is_nullable = 'NO'",
);
assert.includeMembers(
  rows.map((r) => r.column_name),
  ['level'],
);
```

A hostel with a name, a gender and a level should be saved. A hostel with no level should be refused.

```js
await db.query("insert into hostels (name, gender, level) values ('Block L', 'male', 200)");
let error;
try {
  await db.query("insert into hostels (name, gender) values ('Block N', 'male')");
} catch (e) {
  error = e;
}
assert.exists(error);
assert.equal(error.code, '23502');
```
