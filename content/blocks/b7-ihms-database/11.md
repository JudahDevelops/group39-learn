# --description--

Students have a gender and a level, but a hall warden does not need them. Add `gender` and `level` after `role`. `gender` is text with the same `check` as in `hostels`. `level` is a whole number. Neither has `not null`, so a row may leave them empty (`null`).

# --hints--

The `users` table should have the columns `id`, `full_name`, `email`, `password_hash`, `role`, `gender` and `level`, in that order.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'users' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.column_name),
  ['id', 'full_name', 'email', 'password_hash', 'role', 'gender', 'level'],
);
```

`gender` should be `text` and `level` should be a whole number (`integer`).

```js
const { rows } = await db.query(
  "select data_type from information_schema.columns where table_schema = 'public' and table_name = 'users' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.data_type),
  ['integer', 'text', 'text', 'text', 'text', 'text', 'integer'],
);
```

`gender` and `level` may be empty, so do not write `not null` on them.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'users' and is_nullable = 'YES'",
);
assert.includeMembers(
  rows.map((r) => r.column_name),
  ['gender', 'level'],
);
```

A user with no gender and no level, such as a hall warden, should be saved.

```js
await db.query("insert into users (full_name, email, password_hash, role) values ('Warden', 'warden11@example.com', 'x', 'hall_warden')");
```

A user with the gender `other` should be refused. Add `check (gender in ('male', 'female'))` to `gender`.

```js
let error;
try {
  await db.query("insert into users (full_name, email, password_hash, role, gender) values ('G1', 'g1@example.com', 'x', 'student', 'other')");
} catch (e) {
  error = e;
}
assert.exists(error);
assert.equal(error.code, '23514');
```
