# --description--

An allocation connects one student to one bed space, so `allocations` holds two foreign keys. Create a table called `allocations` with `id` (the usual primary key), `student_id` and `bed_space_id`. Each of the last two is a whole number that must have a value and must match a real row, in `users(id)` and `bed_spaces(id)`.
