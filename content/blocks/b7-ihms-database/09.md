# --description--

Everyone who logs in is a row in `users`. Create a table called `users` with `id` (the usual primary key) and three text columns that must all have a value: `full_name`, `email` and `password_hash`. No two users can share an `email`. The database keeps a hash of each password, not the password itself. Chapter B8 builds the login.

```js
const { rows } = await db.query(
  "select a.attname from pg_index i join pg_attribute a on a.attrelid = i.indrelid and a.attnum = any(i.indkey) where i.indrelid = 'users'::regclass and i.indisprimary",

```

`full_name`, `email` and `password_hash` must have a value. Add `not null` after each type.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'users' and is_nullable = 'NO'",
);
assert.includeMembers(
  rows.map((r) => r.column_name),
  ['full_name', 'email', 'password_hash'],
);
```

No two users should share an `email`. Add `unique` after `not null` on the `email` line.

```js
await db.query("insert into users (full_name, email, password_hash) values ('First', 'same@example.com', 'x')");
let error;
try {
  await db.query("insert into users (full_name, email, password_hash) values ('Second', 'same@example.com', 'x')");
} catch (e) {
  error = e;
}
assert.exists(error);
assert.equal(error.code, '23505');
```
