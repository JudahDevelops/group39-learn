# --description--

Add eight bed spaces, two in each room, labelled `1` and `2`. The rooms have the `id` 1 to 4, in the order you added them. Write the labels as text, in quotes.

# --hints--

Your code should add rows with `insert into bed_spaces`.

```js
assert.match(code, /insert\s+into\s+bed_spaces\b/i);
```

The `bed_spaces` table should have 8 rows.

```js
const { rows } = await db.query(
  'select count(*)::int as n from bed_spaces',
);
assert.equal(rows[0].n, 8);
```

Each of the 4 rooms should have two bed spaces, labelled `1` and `2`.

```js
const { rows } = await db.query(
  'select room_id, label from bed_spaces order by room_id, label',
);
assert.deepEqual(
  rows.map((r) => [r.room_id, r.label]),
  [[1, '1'], [1, '2'], [2, '1'], [2, '2'], [3, '1'], [3, '2'], [4, '1'], [4, '2']],
);
```
