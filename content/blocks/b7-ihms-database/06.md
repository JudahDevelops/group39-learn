# --description--

A hostel cannot have two rooms with the same number. Add the rule `unique (hostel_id, number)` after the columns. It is about two columns together: it refuses a repeated number inside one hostel, but another hostel may use the same number.

# --hints--

Two rooms in the same hostel should not share a number. Add `unique (hostel_id, number)` after the columns.

```js
const a = (
  await db.query(
    "insert into hostels (name, gender, level) values ('S6a', 'female', 100) returning id",
  )
).rows[0].id;
await db.query('insert into rooms (hostel_id, number) values ($1, $2)', [a, 'A-101']);
let error;
try {
  await db.query('insert into rooms (hostel_id, number) values ($1, $2)', [a, 'A-101']);
} catch (e) {
  error = e;
}
assert.exists(error);
assert.equal(error.code, '23505');
```

Two different hostels should be able to have a room with the same number.

```js
const b = (
  await db.query(
    "insert into hostels (name, gender, level) values ('S6b', 'female', 100) returning id",
  )
).rows[0].id;
const c = (
  await db.query(
    "insert into hostels (name, gender, level) values ('S6c', 'female', 100) returning id",
  )
).rows[0].id;
await db.query('insert into rooms (hostel_id, number) values ($1, $2)', [b, 'Z-1']);
await db.query('insert into rooms (hostel_id, number) values ($1, $2)', [c, 'Z-1']);
```
