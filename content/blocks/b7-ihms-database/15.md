# --description--

Right now nothing stops two students from holding the same bed. Make the database refuse it. Create a unique index called `one_active_allocation_per_bed` on `allocations (bed_space_id)` that covers only the allocations with the status `active`. This is a **partial unique index**. Ended allocations must not count, because a bed is given to many students over the years.
