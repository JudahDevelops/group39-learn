# --description--

Each book also has an `author` and a `subject`, such as Fiction or Computing. Add both columns to the `create table` statement, after `title`. Both are text and must have a value.

# --hints--

The `books` table should have the columns `id`, `title`, `author` and `subject`, in that order.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'books' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.column_name),
  ['id', 'title', 'author', 'subject'],
);
```

All three new columns should be `text`: `title`, `author` and `subject`.

```js
const { rows } = await db.query(
  "select data_type from information_schema.columns where table_schema = 'public' and table_name = 'books' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.data_type),
  ['integer', 'text', 'text', 'text'],
);
```

`author` and `subject` must have a value. Add `not null` after each type.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'books' and is_nullable = 'NO'",
);
assert.includeMembers(
  rows.map((r) => r.column_name),
  ['author', 'subject'],
);
```

`id` should still be the primary key, numbered by PostgreSQL.

```js
const { rows } = await db.query(
  "select a.attname from pg_index i join pg_attribute a on a.attrelid = i.indrelid and a.attnum = any(i.indkey) where i.indrelid = 'books'::regclass and i.indisprimary",
);
assert.deepEqual(
  rows.map((r) => r.attname),
  ['id'],
```
