# --description--

Now the members. Create a table called `members` with three columns: `id`, the same kind of primary key as in `books`, and `full_name` and `room`, both text that must have a value.

# --hints--

Your code should create a table called `members`.

```js
const { rows } = await db.query(
  "select table_name from information_schema.tables where table_schema = 'public' and table_name = 'members'",
);
assert.lengthOf(rows, 1);
```

The `members` table should have the columns `id`, `full_name` and `room`, in that order.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'members' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.column_name),
  ['id', 'full_name', 'room'],
);
```

`id` should be an `integer`, and `full_name` and `room` should be `text`.

```js
const { rows } = await db.query(
  "select data_type from information_schema.columns where table_schema = 'public' and table_name = 'members' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.data_type),
  ['integer', 'text', 'text'],
);
```

`id` should be the primary key. Add `primary key` after its type.

```js
const { rows } = await db.query(
  "select a.attname from pg_index i join pg_attribute a on a.attrelid = i.indrelid and a.attnum = any(i.indkey) where i.indrelid = 'members'::regclass and i.indisprimary",
);
assert.deepEqual(
  rows.map((r) => r.attname),
  ['id'],
);
```

PostgreSQL should number the rows for you. Write `generated always as identity` before `primary key`.

```js
const { rows } = await db.query(
  "select is_identity from information_schema.columns where table_schema = 'public' and table_name = 'members' and column_name = 'id'",
);
assert.equal(rows[0]?.is_identity, 'YES');
```

`full_name` and `room` must have a value. Add `not null` after each type.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'members' and is_nullable = 'NO'",
);
assert.includeMembers(
  rows.map((r) => r.column_name),
  ['full_name', 'room'],
);
```
