# --description--

In this workshop you build the database of a hostel library: books, the members who borrow them, and the loans. Press **See the finished project** to run the finished database.

Start with the books. Create a table called `books` with two columns. `id` is a whole number that PostgreSQL numbers for you, and it is the primary key. `title` is text that must have a value.

# --hints--

Your code should create a table called `books`.

```js
const { rows } = await db.query(
  "select table_name from information_schema.tables where table_schema = 'public' and table_name = 'books'",
);
assert.lengthOf(rows, 1);
```

The `books` table should have the columns `id` and `title`, in that order.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'books' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.column_name),
  ['id', 'title'],
);
```

`id` should be a whole number (`integer`) and `title` should be `text`.

```js
const { rows } = await db.query(
  "select data_type from information_schema.columns where table_schema = 'public' and table_name = 'books' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.data_type),
  ['integer', 'text'],
);
```

`id` should be the primary key. Add `primary key` after its type.

```js
const { rows } = await db.query(
  "select a.attname from pg_index i join pg_attribute a on a.attrelid = i.indrelid and a.attnum = any(i.indkey) where i.indrelid = 'books'::regclass and i.indisprimary",
);
assert.deepEqual(
  rows.map((r) => r.attname),
  ['id'],
);
```

PostgreSQL should number the rows for you. Write `generated always as identity` before `primary key`.

```js
const { rows } = await db.query(
  "select is_identity from information_schema.columns where table_schema = 'public' and table_name = 'books' and column_name = 'id'",
);
assert.equal(rows[0]?.is_identity, 'YES');
```

`title` must have a value. Add `not null` after `text`.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'books' and is_nullable = 'NO'",
);
assert.includeMembers(
  rows.map((r) => r.column_name),
  ['title'],
);
```

# --help--

## --hint--

`create table` is followed by the table name, then the columns inside brackets, separated by commas.

## --hint--

A column is its name, its type, then its rules. `id` has the type `integer` and the rules `generated always as identity primary key`. `title` has the type `text` and the rule `not null`.
