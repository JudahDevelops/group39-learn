# --description--

A loan is either still `out` or `returned`. Add a `status` column to `loans`, after `member_id`. It is text that must have a value. Give it the default `'out'`, and add a `check` that allows only `'out'` and `'returned'`.

# --hints--

The `loans` table should have the columns `id`, `book_id`, `member_id` and `status`, in that order.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'loans' order by ordinal_position",
);
assert.deepEqual(
  rows.map((r) => r.column_name),
  ['id', 'book_id', 'member_id', 'status'],
);
```

`status` should be `text` and must have a value. Add `not null`.

```js
const { rows } = await db.query(
  "select data_type, is_nullable from information_schema.columns where table_name = 'loans' and column_name = 'status'",
);
assert.equal(rows[0]?.data_type, 'text');
assert.equal(rows[0]?.is_nullable, 'NO');
```

A new loan should start as `out`. Add `default 'out'` to the `status` column.

```js
await db.query("insert into books (title, author, subject) values ('Test book', 'Test author', 'Test')");
await db.query("insert into members (full_name, room) values ('Test member', 'A-101')");
const { rows } = await db.query(
  'insert into loans (book_id, member_id) values ((select min(id) from books), (select min(id) from members)) returning status',
);
assert.equal(rows[0].status, 'out');
```

The `check` should refuse any status other than `out` and `returned`. Add `check (status in ('out', 'returned'))`.

```js
let error;
try {
  await db.query(
    "insert into loans (book_id, member_id, status) values ((select min(id) from books), (select min(id) from members), 'lost')",
  );
} catch (e) {
  error = e;
}
assert.exists(error);
assert.equal(error.code, '23514');
```

The `check` should still allow the status `returned`.

```js
await db.query(
  "insert into loans (book_id, member_id, status) values ((select min(id) from books), (select min(id) from members), 'returned')",
);
```

# --help--

## --hint--

Add a comma after the `member_id` line, then write a new column line for `status`.

## --hint--

`default 'out'` sets the value used when none is given. `check (status in ('out', 'returned'))` allows only those two values. Both go after `not null`.

Change the statement to:

create table loans (
  id integer generated always as identity primary key,
  book_id integer not null references books(id),
  member_id integer not null references members(id),
  status text not null default 'out' check (status in ('out', 'returned'))
);
