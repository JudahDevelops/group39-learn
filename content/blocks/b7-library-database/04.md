# --description--

A loan connects one book to one member, so `loans` holds two foreign keys. Create a table called `loans` with `id` (the usual primary key), `book_id` and `member_id`. Each of the last two is a whole number that must have a value and must match a real row, in `books(id)` and `members(id)`.

# --hints--

Your code should create a table called `loans`.

```js
const { rows } = await db.query(
  "select table_name from information_schema.tables where table_schema = 'public' and table_name = 'loans'",

assert.lengthOf(rows, 1);
```



`id` should be the primary key, numbered by PostgreSQL: `generated always as identity primary key`.

```js
const { rows } = await db.query(
  "select a.attname from pg_index i join pg_attribute a on a.attrelid = i.indrelid and a.attnum = any(i.indkey) where i.indrelid = 'loans'::regclass and i.indisprimary",
);
assert.deepEqual(
  rows.map((r) => r.attname),
  ['id'],
);
const identity = await db.query(
  "select is_identity from information_schema.columns where table_schema = 'public' and table_name = 'loans' and column_name = 'id'",
);
assert.equal(identity.rows[0]?.is_identity, 'YES');
```

`book_id` and `member_id` must have a value. Add `not null` after each type.

```js
const { rows } = await db.query(
  "select column_name from information_schema.columns where table_schema = 'public' and table_name = 'loans' and is_nullable = 'NO'",
);
assert.includeMembers(
  rows.map((r) => r.column_name),
  ['book_id', 'member_id'],
);
```

`book_id` should point to a real book. Add `references books(id)` after its type.

```js
const { rows } = await db.query(
  "select confrelid::regclass::text as ref from pg_constraint c join pg_attribute a on a.attrelid = c.conrelid and a.attnum = any(c.conkey) where c.conrelid = 'loans'::regclass and c.contype = 'f' and a.attname = 'book_id'",
);
assert.deepEqual(
  rows.map((r) => r.ref),
  ['books'],
);
```

`member_id` should point to a real member. Add `references members(id)` after its type.


# --solutions--

```sql file=query.sql
-- Books in the hostel library.
create table books (
  id integer generated always as identity primary key,
  title text not null,
  author text not null,
  subject text not null
);

-- Members who borrow books.
create table members (
  id integer generated always as identity primary key,
  full_name text not null,
  room text not null
);

-- Loans: which member has which book.
create table loans (
  id integer generated always as identity primary key,
  book_id integer not null references books(id),
  member_id integer not null references members(id)
);
```

# --help--

## --hint--

A foreign key is the word `references`, then the other table and its `id` in brackets.

## --hint--

`book_id integer not null references books(id)`. `member_id` works the same way, with `members`.
