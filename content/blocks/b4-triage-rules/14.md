# --description--

The function only knows the urgent keywords. Replace the loop with two loops, so that it checks normal and low as well, most serious first. The outer loop goes through the list `["urgent", "normal", "low"]` with a variable called `urgency`. The inner loop goes through `URGENCY_KEYWORDS[urgency]` and returns `urgency` at the first keyword found. If nothing matches, the function still returns `None`. What to do then is an open design decision (<a href="/reference/decisions" target="_blank" rel="noopener">Group decisions</a>), and step 22 uses a placeholder.

```python file=triage.py
# IHMS triage and escalation rules

def deadline_hours(urgency: str) -> int:
    """Return the resolution deadline in hours for an urgency level."""
    if urgency == "urgent":
        return 24
    if urgency == "normal":
        return 72
    return 168


def escalation_level(elapsed_hours: float, deadline_hours: float) -> int:
    if elapsed_hours < deadline_hours:
        return 0
    if elapsed_hours < 2 * deadline_hours:
        return 1
    return 2


URGENCY_KEYWORDS = {
    "urgent": ["burst", "flood", "spark", "exposed wire", "no water", "broken lock"],
    "normal": ["leaking tap", "faulty socket", "broken bed", "blocked drain"],
    "low": ["paint", "loose handle", "squeaking door"],
}


def triage_urgency(description: str) -> str | None:
    text = description.lower()
    for urgency in ["urgent", "normal", "low"]:      # most serious first
        for keyword in URGENCY_KEYWORDS[urgency]:
            if keyword in text:
                return urgency
    return None   # nothing matched: what happens next is a group decision
```
