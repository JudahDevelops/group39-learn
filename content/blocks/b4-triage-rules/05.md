# --description--

Now the escalation rule. *t* is the time a complaint has been open and *d* is its deadline. The level *L* is 0 while *t* < *d*. Write `escalation_level(elapsed_hours: float, deadline_hours: float) -> int` and make it return `0` when `elapsed_hours` is less than `deadline_hours`. Inside this function, `deadline_hours` is the number passed in, not the function from step 1.

def deadline_hours(urgency: str) -> int:

    if urgency == "urgent":

    if urgency == "normal":
        return 72
    return 168

    if elapsed_hours < deadline_hours:
        return 0
