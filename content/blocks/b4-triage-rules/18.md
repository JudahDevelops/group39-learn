# --description--

Give `triage_category` the same shape as `triage_urgency`. Make a variable `text` that holds the lowered description. Loop over the categories in this order: `"plumbing"`, `"electrical"`, `"carpentry"`, `"sanitation"`. For each one, loop over its keywords in `CATEGORY_KEYWORDS` and return the category at the first keyword found. Keep `return "other"` as the last line.
