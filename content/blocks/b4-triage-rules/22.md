# --description--

A complaint with no urgency has no deadline, so `triage` needs a value to fall back on. Before the `return`, add an `if` that checks whether `urgency` `is None`, and inside it set `urgency` to `NO_KEYWORD_URGENCY`. `is None` is how Python asks whether a value is nothing. The decision is still open (<a href="/reference/decisions" target="_blank" rel="noopener">Group decisions</a>).

# --hints--

"My tap is leaking" has no urgency keyword, so its `"urgency"` should be `"normal"`, the placeholder.

```py
assert triage('My tap is leaking')['urgency'] == 'normal'
```

"water dey drip from ceiling since morning" has no urgency keyword, so its `"urgency"` should be `"normal"`.

```py
assert triage('water dey drip from ceiling since morning')['urgency'] == 'normal'
```

A complaint that matches a keyword should keep its own urgency. "The pipe in the bathroom has burst" should still be `"urgent"`.

```py
assert triage('The pipe in the bathroom has burst')['urgency'] == 'urgent'
```

"The squeaking door keeps me awake" should still be `"low"`.

```py
assert triage('The squeaking door keeps me awake')['urgency'] == 'low'
```

Your function should read the placeholder from `NO_KEYWORD_URGENCY`, so that changing that one line changes the decision. Do not type `"normal"` again inside `triage`.

```py
NO_KEYWORD_URGENCY = 'low'
assert triage('My tap is leaking')['urgency'] == 'low'
```
