# --description--

One keyword is not enough. `URGENCY_RULES` is an array of objects. Each has an `urgency` and a list of `keywords`, and the most serious urgency comes first.

Replace the `if` for `burst` with two loops. The outer loop goes through `URGENCY_RULES`. The inner loop goes through the `keywords` of each rule. When `text.includes(keyword)` is true, return `rule.urgency`.

# --hints--

`triageUrgency("There's a spark coming from the socket")` should return `urgent`. Check every keyword of every rule.

```js
assert.strictEqual(triageUrgency("There's a spark coming from the socket"), 'urgent');
assert.strictEqual(triageUrgency('No water in the bathroom since morning'), 'urgent');
```

`triageUrgency("The squeaking door keeps me awake")` should return `low`, and so should a description with the keyword `paint`.

```js
assert.strictEqual(triageUrgency('The squeaking door keeps me awake'), 'low');
assert.strictEqual(triageUrgency('The paint on the wall is peeling'), 'low');
```

`triageUrgency("The leaking tap in the kitchen")` should return `normal`, because `leaking tap` is a keyword of the normal rule.

```js
assert.strictEqual(triageUrgency('The leaking tap in the kitchen'), 'normal');
```

When a description matches more than one rule, the most serious urgency should win. `triageUrgency("A spark near the squeaking door")` should return `urgent`.

```js
assert.strictEqual(triageUrgency('A spark near the squeaking door'), 'urgent');
```

A description with no keyword should return `normal`. `triageUrgency("My tap is leaking")` has the words of `leaking tap` in a different order, so nothing matches.

```js
assert.strictEqual(triageUrgency('My tap is leaking'), 'normal');
assert.strictEqual(triageUrgency('water dey drip from ceiling since morning'), 'normal');
```

Your function should read the keywords from `URGENCY_RULES`, not from keywords typed into the function. A keyword added to the `low` rule should make `triageUrgency` return `low`.

```js
const rule = URGENCY_RULES.find((r) => r.urgency === 'low');
rule.keywords.push('graffiti');
try {
  assert.strictEqual(triageUrgency('Graffiti on the wall'), 'low');
} finally { rule.keywords.pop(); }
```
