# --description--

The student never chooses the category or the urgency. The system sets them from the words in the description. Later the server will do this. Until it exists, the page needs its own version.

Start with the urgency. Write a function `triageUrgency` with one parameter, `description`, that returns `"normal"`. This is a placeholder: what to do when no keyword matches is one of six open design decisions, and the group has not settled it. See <a href="/reference/decisions" target="_blank" rel="noopener">Group decisions</a>.

# --hints--

Your code should define a function called `triageUrgency`.

```js
assert.isFunction(triageUrgency);
```

`triageUrgency("Anything at all")` should return `normal`, the placeholder for a description with no keyword.

```js
assert.strictEqual(triageUrgency('Anything at all'), 'normal');
```

// Triage rules. The urgency keywords come from Table IV of the paper.
// The paper does not list category keywords, so the category list is a starting set to improve.
const URGENCY_RULES = [
  { urgency: "urgent", keywords: ["burst", "flood", "spark", "exposed wire", "no water", "broken lock"] },
  { urgency: "normal", keywords: ["leaking tap", "faulty socket", "broken bed", "blocked drain"] },
  { urgency: "low", keywords: ["paint", "loose handle", "squeaking door"] },
];

const CATEGORY_RULES = [
  { category: "plumbing", keywords: ["pipe", "tap", "leak", "water", "drain", "toilet", "shower", "flood"] },
  { category: "electrical", keywords: ["socket", "light", "bulb", "wire", "spark", "fan", "switch", "power"] },
  { category: "carpentry", keywords: ["door", "bed", "window", "wardrobe", "handle", "lock", "chair", "table"] },
  { category: "sanitation", keywords: ["dirty", "smell", "refuse", "waste", "cockroach", "rat", "bin"] },
];

// Helpers from the lesson on the DOM and events.
function cell(text) {
  const td = document.createElement("td");
  td.textContent = text;
  return td;
}

function badge(urgency) {
  const td = document.createElement("td");
  const span = document.createElement("span");
  span.classList.add("badge", urgency);
  span.textContent = urgency;
  td.append(span);
  return td;
}

const form = document.querySelector("#complaint-form");
const descriptionBox = document.querySelector("#description");
const message = document.querySelector("#message");

--editable-region--

--editable-region--

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const description = descriptionBox.value.trim();

  if (description === "") {
    message.textContent = "Describe the fault before you submit.";
    return;
  }

  console.log("Would send:", description);
  message.textContent = "";
});
