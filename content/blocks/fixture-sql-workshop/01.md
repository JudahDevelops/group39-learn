# --description--

The warden wants a list of every room. Write `select *` to ask for every column, then `from rooms` to name the table. End the line with a semicolon `;`.

# --hints--

Your query should select from the `rooms` table.

```js
assert.match(code, /select\s+[\s\S]*from\s+rooms\b/i);
```

Your query should return all 5 rooms.

```js
const { rows } = await db.query(code);
assert.lengthOf(rows, 5);
```

Your query should return every column: `id`, `room_number`, `hall` and `beds`.

```js
const { rows } = await db.query(code);
assert.sameMembers(Object.keys(rows[0] ?? {}), ['id', 'room_number', 'hall', 'beds']);
```
