## --question--

### --text--

What does the `h1` element make?

### --distractors--

- A paragraph of text
- A button that can be clicked
- A bulleted list

### --answer--

The main heading of a page

### --explanation--

`h1` is the top-level heading. Paragraphs use `p`, buttons use `button`, and bulleted lists use `ul`.

## --question--

### --text--

Which pair of tags wraps a paragraph?

### --distractors--

- `<h1>` and `</h1>`
- `<para>` and `</para>`
- `<text>` and `</text>`

### --answer--

`<p>` and `</p>`

### --explanation--

A paragraph is a `p` element. The other names are not HTML elements, and `h1` makes a heading.

## --question--

### --text--

Where does the visible content of a page go?

### --distractors--

- Inside the `head` element
- Inside the `title` element
- Before the `html` element

### --answer--

Inside the `body` element

### --explanation--

The `body` holds everything the visitor sees. The `head` holds information about the page, such as its title.

## --question--

### --text--

What is the closing tag for `<button>`?

### --distractors--

- `</btn>`
- `<button/>`
- `<end button>`

### --answer--

`</button>`

### --explanation--

A closing tag repeats the element name with a `/` in front. A button needs one, so `<button/>` does not end it.

## --question--

### --text--

Which element is one item in a bulleted list?

### --distractors--

- `ul`
- `ol`
- `item`

### --answer--

`li`

### --explanation--

`ul` wraps the whole bulleted list, and each item inside it is an `li`. `ol` wraps a numbered list. There is no `item` element.

## --question--

### --text--

What does the `title` element inside `head` set?

### --distractors--

- The main heading on the page
- The first paragraph
- The background colour

### --answer--

The text on the browser tab

### --explanation--

The title shows on the browser tab and in search results. The main heading is made with `h1` inside `body`.
