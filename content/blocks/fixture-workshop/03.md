# --description--

Last, add a `button` element under the paragraph with the text `Got it`. Students would press it to say they have read the notice.

# --hints--

Your page should have exactly one `button` element.

```js
assert.lengthOf(document.querySelectorAll('button'), 1);
```

Your `button` element should come after your `p` element.

```js
const p = document.querySelector('p');
const button = document.querySelector('button');
assert.isTrue(Boolean(p.compareDocumentPosition(button) & Node.DOCUMENT_POSITION_FOLLOWING));
```

Your `button` element should have the text `Got it`.

```js
assert.equal(document.querySelector('button')?.textContent.trim(), 'Got it');
```

## --hint--

A button is an element too. It has an opening tag, the text, and a closing tag.

## --hint--

The tags are `<button>` and `</button>`.

## --hint--

Type `<button>Got it</button>` on the empty line, after the paragraph.
