# --description--

Every page starts with some content inside the `body` element. In this workshop you will build a notice that a hall warden could pin on a board.

Add an `h1` element with the text `Hall Notice`. An `h1` element is the main heading of a page.

# --hints--

Your page should have exactly one `h1` element.

```js
assert.lengthOf(document.querySelectorAll('h1'), 1);
```

Your `h1` element should have the text `Hall Notice`.

```js
assert.equal(document.querySelector('h1')?.textContent.trim(), 'Hall Notice');
```

Your `h1` element needs a closing tag.

```js
assert.match(code, /<\/h1>/i);
```

# --help--

## --hint--

An element has an opening tag, the text, and a closing tag.

## --hint--

The opening tag is `<h1>` and the closing tag is `</h1>`. The text goes between them.

## --hint--

Type `<h1>Hall Notice</h1>` on the empty line inside the `body` element.
