# --description--

Add a route for `GET /{complaint_id}` with `response_model=ComplaintDetail`. `{complaint_id}` is a path parameter, so give the argument the type hint `int`. Use `find_complaint` and return what it finds. If it finds nothing, raise an `HTTPException` with status code 404 and the detail `Complaint not found`.

# --hints--

`GET /api/complaints/{id}` should answer with status 200 for a complaint that exists.

```py
new = (await client.post('/api/complaints', json={'description': 'The pipe in the bathroom has burst'})).json()
r = await client.get('/api/complaints/' + str(new['id']))
assert r.status_code == 200
```

The reply should be the complaint with that `id` and `description`.

```py
new = (await client.post('/api/complaints', json={'description': 'The pipe in the bathroom has burst'})).json()
r = await client.get('/api/complaints/' + str(new['id']))
assert r.json()['id'] == new['id']
assert r.json()['description'] == 'The pipe in the bathroom has burst'
```

The reply should have the fields of `ComplaintOut` plus `history`. Add `response_model=ComplaintDetail` to the decorator.

```py
new = (await client.post('/api/complaints', json={'description': 'The pipe in the bathroom has burst'})).json()
r = await client.get('/api/complaints/' + str(new['id']))
assert set(r.json()) == {'id', 'description', 'category', 'urgency', 'status', 'deadline', 'escalation_level', 'created_at', 'resolved_at', 'history'}
```

The `history` should hold the entry made when the complaint was lodged: `Lodged and triaged as urgent plumbing`.

```py
new = (await client.post('/api/complaints', json={'description': 'The pipe in the bathroom has burst'})).json()
r = await client.get('/api/complaints/' + str(new['id']))
events = [h['event'] for h in r.json()['history']]
assert events == ['Lodged and triaged as urgent plumbing']
```

A complaint that does not exist should give status 404. Raise an `HTTPException` when `find_complaint` returns `None`.

```py
r = await client.get('/api/complaints/999999')
assert r.status_code == 404
```

The 404 should have the detail `Complaint not found`.

```py
r = await client.get('/api/complaints/999999')
assert r.json()['detail'] == 'Complaint not found'
```

An id that is not a number, such as `abc`, should give status 422. The type hint `int` does that for you.

```py
r = await client.get('/api/complaints/abc')
assert r.status_code == 422
```

```python file=routers/complaints.py
# The complaint endpoints.

from datetime import datetime, timedelta, timezone

from fastapi import APIRouter, HTTPException

from schemas import ComplaintDetail, ComplaintIn, ComplaintOut
from services.triage import triage

router = APIRouter(prefix="/complaints", tags=["complaints"])

COMPLAINTS = []


def by_deadline(complaint):
    return complaint["deadline"]


@router.get("", response_model=list[ComplaintOut])
def list_complaints(status: str | None = None):
    complaints = COMPLAINTS
    if status is not None:

    return sorted(complaints, key=by_deadline)

def create_complaint(body: ComplaintIn):

        "id": len(COMPLAINTS) + 1,

    return complaint


def find_complaint(complaint_id: int):
    for complaint in COMPLAINTS:

    return None
```

```python file=services/triage.py
# IHMS triage rules, from chapter B4


def deadline_hours(urgency: str) -> int:
    """Return the resolution deadline in hours for an urgency level."""
    if urgency == "urgent":
        return 24
    if urgency == "normal":
        return 72
    return 168


URGENCY_KEYWORDS = {
    "urgent": ["burst", "flood", "spark", "exposed wire", "no water", "broken lock"],
    "normal": ["leaking tap", "faulty socket", "broken bed", "blocked drain"],
    "low": ["paint", "loose handle", "squeaking door"],
}


def triage_urgency(description: str) -> str | None:
    text = description.lower()
    for urgency in ["urgent", "normal", "low"]:      # most serious first
        for keyword in URGENCY_KEYWORDS[urgency]:
            if keyword in text:
                return urgency
    return None   # nothing matched: what happens next is a group decision


CATEGORY_KEYWORDS = {
    "plumbing": ["pipe", "tap", "leak", "water", "drain", "toilet", "shower", "flood"],
    "electrical": ["socket", "light", "bulb", "wire", "spark", "fan", "switch", "power"],
    "carpentry": ["door", "bed", "window", "wardrobe", "handle", "lock", "chair", "table"],
    "sanitation": ["dirty", "smell", "refuse", "waste", "cockroach", "rat", "bin"],
}


def triage_category(description: str) -> str:
    text = description.lower()
    for category in ["plumbing", "electrical", "carpentry", "sanitation"]:
        for keyword in CATEGORY_KEYWORDS[category]:
            if keyword in text:
                return category
    return "other"


# Placeholder until the group decides: the urgency when no keyword matches
NO_KEYWORD_URGENCY = "normal"


def triage(description: str) -> dict:
    category = triage_category(description)
    urgency = triage_urgency(description)
    if urgency is None:
        urgency = NO_KEYWORD_URGENCY
    return {
        "category": category,
        "urgency": urgency,
        "deadline_hours": deadline_hours(urgency),
    }
```

## --hint--

This is the same pattern as `GET /api/proverbs/{proverb_id}` in the Proverbs API. Put the variable in braces in the path, and give the function an argument with the same name.

## --hint--

The decorator is `@router.get("/{complaint_id}", response_model=ComplaintDetail)`. In the function: find the complaint, `if complaint is None:` raise the error, then return the complaint.

## --hint--

