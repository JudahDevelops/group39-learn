# --description--

A complaint's first history entry says how it was triaged. Add the key `history`: a list with one dictionary. Its `event` is `Lodged and triaged as urgent plumbing`, with the complaint's own urgency and category in place of `urgent` and `plumbing` (write it as an f-string). Its `actor_id` is `None`, and its `at` is `now`.

# --hints--

The reply should have a `history` list with one entry.

```py
r = await client.post('/api/complaints', json={'description': 'The pipe in the bathroom has burst'})
assert isinstance(r.json()['history'], list)
assert len(r.json()['history']) == 1
```

The entry's `event` should be `Lodged and triaged as urgent plumbing` for "The pipe in the bathroom has burst". Use an f-string with `result['urgency']` and `result['category']`.

```py
r = await client.post('/api/complaints', json={'description': 'The pipe in the bathroom has burst'})
assert r.json()['history'][0]['event'] == 'Lodged and triaged as urgent plumbing'
```

A different complaint should get its own words: "The squeaking door keeps me awake" should be `Lodged and triaged as low carpentry`.

```py
r = await client.post('/api/complaints', json={'description': 'The squeaking door keeps me awake'})
assert r.json()['history'][0]['event'] == 'Lodged and triaged as low carpentry'
```

The entry should have `actor_id` set to `None`, because nobody is logged in yet, and `at` set to `now`, the same time as `created_at`.

```py
r = await client.post('/api/complaints', json={'description': 'The pipe in the bathroom has burst'})
entry = r.json()['history'][0]
assert entry['actor_id'] is None
assert entry['at'] == r.json()['created_at']
```

```python file=services/triage.py
# IHMS triage rules, from chapter B4


def deadline_hours(urgency: str) -> int:
    """Return the resolution deadline in hours for an urgency level."""
    if urgency == "urgent":
        return 24
    if urgency == "normal":
        return 72
    return 168


URGENCY_KEYWORDS = {
    "urgent": ["burst", "flood", "spark", "exposed wire", "no water", "broken lock"],
    "normal": ["leaking tap", "faulty socket", "broken bed", "blocked drain"],
    "low": ["paint", "loose handle", "squeaking door"],
}


def triage_urgency(description: str) -> str | None:
    text = description.lower()
    for urgency in ["urgent", "normal", "low"]:      # most serious first
        for keyword in URGENCY_KEYWORDS[urgency]:
            if keyword in text:
                return urgency
    return None   # nothing matched: what happens next is a group decision


CATEGORY_KEYWORDS = {
    "plumbing": ["pipe", "tap", "leak", "water", "drain", "toilet", "shower", "flood"],
    "electrical": ["socket", "light", "bulb", "wire", "spark", "fan", "switch", "power"],
    "carpentry": ["door", "bed", "window", "wardrobe", "handle", "lock", "chair", "table"],
    "sanitation": ["dirty", "smell", "refuse", "waste", "cockroach", "rat", "bin"],
}


def triage_category(description: str) -> str:
    text = description.lower()
    for category in ["plumbing", "electrical", "carpentry", "sanitation"]:
        for keyword in CATEGORY_KEYWORDS[category]:
            if keyword in text:
                return category
    return "other"


# Placeholder until the group decides: the urgency when no keyword matches
NO_KEYWORD_URGENCY = "normal"


def triage(description: str) -> dict:
    category = triage_category(description)
    urgency = triage_urgency(description)
    if urgency is None:
        urgency = NO_KEYWORD_URGENCY
    return {
        "category": category,
        "urgency": urgency,
        "deadline_hours": deadline_hours(urgency),
    }
```

# --help--

## --hint--

An f-string is a string that starts with `f` and holds Python values inside braces: `f"Hello {name}"`. Use single quotes inside the braces, as in `result['urgency']`, so they do not end the string.

## --hint--

The key holds a list `[...]`, and the list holds one dictionary `{...}` with three keys: `event`, `actor_id` and `at`.

## --hint--

Type this on the empty lines:

```python
        "history": [
            {
                "event": f"Lodged and triaged as {result['urgency']} {result['category']}",
                "actor_id": None,
                "at": now,
            }
        ],
```
