# --description--

Add a route for `GET /api/health` that returns the dictionary `{"status": "ok"}`. It lets anyone check that the server is up.

# --hints--

Your app should answer `GET /api/health` with status 200. Check the decorator: `@app.get("/api/health")`.

```py
r = await client.get('/api/health')
assert r.status_code == 200
```

The reply should be `{"status": "ok"}`.

```py
r = await client.get('/api/health')
assert r.json() == {'status': 'ok'}
```

# --help--

## --hint--

A route is a decorator on top of a function. The decorator holds the method and the path, and the function holds what to send back.

## --hint--

Use `@app.get("/api/health")`, then `def health():`, and return a dictionary with the key `status`.

## --hint--

Type this on the empty lines:

```python
@app.get("/api/health")
def health():
    return {"status": "ok"}
```
