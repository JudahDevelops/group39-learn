# --description--

A new proverb needs an `id` that nobody uses. Write a function `next_id()` that returns one more than the highest `id` in `PROVERBS`. Do not use `len(PROVERBS)`: after a delete, the length and the highest `id` are no longer the same.

# --hints--

Your code should define a function called `next_id`.

```py
assert has_function('next_id')
```

`next_id()` should return one more than the highest `id`, which is 7 for the six proverbs.

```py
import main
assert main.next_id() == 7
```

`next_id()` should work from the highest `id`, even when the ids are not in order.

```py
import main
saved = list(main.PROVERBS)
try:
    main.PROVERBS[:] = [{'id': 2}, {'id': 9}, {'id': 4}]
    assert main.next_id() == 10
finally:
    main.PROVERBS[:] = saved
```

```python file=main.py
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

from proverbs import PROVERBS

app = FastAPI(title="Proverbs API")


class ProverbIn(BaseModel):
    text: str
    language: str
    meaning: str


def next_id() -> int:
    highest = 0
    for proverb in PROVERBS:
        if proverb["id"] > highest:
            highest = proverb["id"]
    return highest + 1


def find_proverb(proverb_id: int):
    for proverb in PROVERBS:
```
