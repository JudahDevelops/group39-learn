# --description--

Add a route for `GET /api/proverbs` that returns the whole `PROVERBS` list.

# --hints--

Your app should answer `GET /api/proverbs` with status 200.

```py
r = await client.get('/api/proverbs')
assert r.status_code == 200
```

`GET /api/proverbs` should return all 6 proverbs.

```py
r = await client.get('/api/proverbs')
assert isinstance(r.json(), list)
assert len(r.json()) == 6
```

Each proverb should have an `id`, a `language`, the `text` and its `meaning`.

```py
r = await client.get('/api/proverbs')
assert set(r.json()[0]) == {'id', 'language', 'text', 'meaning'}
```

# --solutions--

```python file=main.py
from fastapi import FastAPI

from proverbs import PROVERBS

app = FastAPI(title="Proverbs API")


@app.get("/api/health")
def health():
    return {"status": "ok"}


@app.get("/api/proverbs")
def list_proverbs():
    return PROVERBS
```

## --hint--

This route works like the health route, but it returns a list instead of a dictionary. FastAPI turns lists into JSON too.

## --hint--

Use `@app.get("/api/proverbs")` and a function called `list_proverbs`. It returns `PROVERBS`.

## --hint--

Type this on the empty lines:

```python
@app.get("/api/proverbs")
def list_proverbs():
    return PROVERBS
```
