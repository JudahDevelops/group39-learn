# --description--

Add a route for `DELETE /api/proverbs/{proverb_id}`. Find the proverb with `find_proverb`, take it out of the list with `PROVERBS.remove(proverb)`, and return it.

# --hints--

`DELETE /api/proverbs/1` should answer with status 200.

```py
r = await client.delete('/api/proverbs/1')
assert r.status_code == 200
```

The reply should be the proverb that was removed. Deleting proverb 2 should return the proverb with `id` 2.

```py
r = await client.delete('/api/proverbs/2')
assert r.json()['id'] == 2
```

A deleted proverb should be gone from `GET /api/proverbs`.

```py
before = [p['id'] for p in (await client.get('/api/proverbs')).json()]
await client.delete('/api/proverbs/3')
after = [p['id'] for p in (await client.get('/api/proverbs')).json()]
assert 3 in before
assert 3 not in after
```

After a delete, `GET /api/proverbs/4` should still work for the proverbs that are left, and a deleted one should be a 404.

```py
await client.delete('/api/proverbs/4')
assert (await client.get('/api/proverbs/4')).status_code == 404
assert (await client.get('/api/proverbs/5')).status_code == 200
```

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

from proverbs import PROVERBS

app = FastAPI(title="Proverbs API")


class ProverbIn(BaseModel):
    text: str = Field(min_length=10)
    language: str
    meaning: str


def next_id() -> int:
    highest = 0
    for proverb in PROVERBS:
        if proverb["id"] > highest:
            highest = proverb["id"]
    return highest + 1


def find_proverb(proverb_id: int):
    for proverb in PROVERBS:
        if proverb["id"] == proverb_id:
            return proverb
    return None


@app.get("/api/health")
def health():
    return {"status": "ok"}


@app.get("/api/proverbs")
def list_proverbs(language: str | None = None):
    if language is None:
        return PROVERBS
    return [p for p in PROVERBS if p["language"].lower() == language.lower()]


@app.get("/api/proverbs/{proverb_id}")
def get_proverb(proverb_id: int):
    proverb = find_proverb(proverb_id)
    if proverb is None:
        raise HTTPException(status_code=404, detail="Proverb not found")
    return proverb


@app.post("/api/proverbs", status_code=201)
def create_proverb(body: ProverbIn):
    for proverb in PROVERBS:
        if proverb["text"] == body.text:
            raise HTTPException(status_code=409, detail="That proverb is already in the list")
    proverb = {
        "id": next_id(),
        "text": body.text,
        "language": body.language,
        "meaning": body.meaning,
    }
    PROVERBS.append(proverb)
    return proverb

## --hint--

Deleting works like reading one proverb: the same path with a path parameter, but with the method `DELETE`.

## --hint--

Use `@app.delete(...)`. `PROVERBS.remove(proverb)` takes an item out of the list. Return the proverb you removed.

## --hint--

Type this on the empty lines:

```python
@app.delete("/api/proverbs/{proverb_id}")
def delete_proverb(proverb_id: int):
    proverb = find_proverb(proverb_id)
    PROVERBS.remove(proverb)
    return proverb
```
