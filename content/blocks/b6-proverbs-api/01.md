# --description--

In this workshop you build an API that serves well-known Nigerian proverbs, each with its meaning in plain English. Press **See the finished project** to try the finished API in the Requests panel.

The proverbs are already written in `proverbs.py`. In `main.py`, import `FastAPI` from `fastapi`. Then create the app in a variable called `app`, with the title `Proverbs API`.

# --hints--

Your code should import `FastAPI` from `fastapi`. Start with `from fastapi import FastAPI`.

```py
import re
assert re.search(r'from\s+fastapi\s+import\s+[^\n]*\bFastAPI\b', _code['main.py'])
```

Your `app` should be a `FastAPI` app. Write `app = FastAPI(...)`.

```py
from fastapi import FastAPI
assert isinstance(app, FastAPI)
```

Your app should have the title `Proverbs API`. Set `title="Proverbs API"` inside `FastAPI(...)`.

```py
assert app.title == 'Proverbs API'
```
