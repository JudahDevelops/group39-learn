# --description--

Several routes will need to find one proverb by its `id`. Write a function `find_proverb(proverb_id: int)` that loops through `PROVERBS` and returns the proverb whose `id` equals `proverb_id`. If there is none, it returns `None`.

# --hints--

Your code should define a function called `find_proverb`.

```py
assert has_function('find_proverb')
```

`find_proverb(3)` should return the proverb with `id` 3, which is a Hausa proverb.

```py
import main
found = main.find_proverb(3)
assert found is not None and found['id'] == 3
assert found['language'] == 'Hausa'
```

`find_proverb(99)` should return `None`, because there is no proverb 99. Return `None` after the loop.

```py
import main
assert main.find_proverb(99) is None
```

```python file=main.py
from fastapi import FastAPI

from proverbs import PROVERBS

app = FastAPI(title="Proverbs API")


def find_proverb(proverb_id: int):
    for proverb in PROVERBS:
        if proverb["id"] == proverb_id:
            return proverb
    return None


@app.get("/api/health")
def health():
    return {"status": "ok"}


@app.get("/api/proverbs")
def list_proverbs():
    return PROVERBS
```

## --hint--

This is a plain Python function, not a route, so it has no decorator. Loop through `PROVERBS` and look at each `proverb["id"]`.

## --hint--

Inside the loop, `if proverb["id"] == proverb_id:` returns the proverb. After the loop ends without a match, `return None`.

## --hint--

Type this on the empty lines:

```python
def find_proverb(proverb_id: int):
    for proverb in PROVERBS:
        if proverb["id"] == proverb_id:
            return proverb
    return None
```
