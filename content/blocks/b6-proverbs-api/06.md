# --description--

Add a route for `GET /api/proverbs/{proverb_id}`. `{proverb_id}` is a path parameter, so give the function argument the type hint `int`. Use `find_proverb` and return what it finds.

# --hints--

`GET /api/proverbs/3` should answer with status 200.

```py
r = await client.get('/api/proverbs/3')
assert r.status_code == 200
```

`GET /api/proverbs/3` should return the proverb with `id` 3, a Hausa proverb.

```py
r = await client.get('/api/proverbs/3')
assert r.json()['id'] == 3
assert r.json()['language'] == 'Hausa'
```

`GET /api/proverbs/abc` should answer with status 422. Give the function argument the type hint `int`.

```py
r = await client.get('/api/proverbs/abc')
assert r.status_code == 422
```

```python file=main.py
from fastapi import FastAPI

from proverbs import PROVERBS

app = FastAPI(title="Proverbs API")


def find_proverb(proverb_id: int):
    for proverb in PROVERBS:
        if proverb["id"] == proverb_id:
            return proverb
    return None


@app.get("/api/health")
def health():
    return {"status": "ok"}


@app.get("/api/proverbs")
def list_proverbs():
    return PROVERBS


@app.get("/api/proverbs/{proverb_id}")
def get_proverb(proverb_id: int):
    return find_proverb(proverb_id)
```
