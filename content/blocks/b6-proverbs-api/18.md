# --description--

Deleting a proverb that is not there should be a 404 too. In `delete_proverb`, raise the same `HTTPException` as in `get_proverb` when `find_proverb` finds nothing.

# --hints--

`DELETE /api/proverbs/99` should answer with status 404.

```py
r = await client.delete('/api/proverbs/99')
assert r.status_code == 404
```

The 404 reply should have the detail `Proverb not found`.

```py
r = await client.delete('/api/proverbs/99')
assert r.json()['detail'] == 'Proverb not found'
```

Deleting the same proverb twice should be 200 the first time and 404 the second time.

```py
first = await client.delete('/api/proverbs/6')
second = await client.delete('/api/proverbs/6')
assert first.status_code == 200
assert second.status_code == 404
```

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

from proverbs import PROVERBS

app = FastAPI(title="Proverbs API")


class ProverbIn(BaseModel):
    text: str = Field(min_length=10)
    language: str
    meaning: str


def next_id() -> int:
    highest = 0
    for proverb in PROVERBS:
        if proverb["id"] > highest:
            highest = proverb["id"]
    return highest + 1


def find_proverb(proverb_id: int):
    for proverb in PROVERBS:
        if proverb["id"] == proverb_id:
            return proverb
    return None


@app.get("/api/health")
def health():
    return {"status": "ok"}


@app.get("/api/proverbs")
def list_proverbs(language: str | None = None):
    if language is None:
        return PROVERBS
    return [p for p in PROVERBS if p["language"].lower() == language.lower()]


@app.get("/api/proverbs/{proverb_id}")
def get_proverb(proverb_id: int):
    proverb = find_proverb(proverb_id)
    if proverb is None:
        raise HTTPException(status_code=404, detail="Proverb not found")
    return proverb


@app.post("/api/proverbs", status_code=201)
def create_proverb(body: ProverbIn):
    for proverb in PROVERBS:
        if proverb["text"] == body.text:
            raise HTTPException(status_code=409, detail="That proverb is already in the list")
    proverb = {
        "id": next_id(),
        "text": body.text,
        "language": body.language,

    return proverb


@app.delete("/api/proverbs/{proverb_id}")

# --help--

## --hint--

Without a check, `PROVERBS.remove(None)` makes Python raise an error, and the caller gets a 500. A 404 says what really happened.

## --hint--

Check `if proverb is None:` before `PROVERBS.remove(proverb)`, and raise the exception inside it.

## --hint--

Add these lines after `proverb = find_proverb(proverb_id)`:

```python
    if proverb is None:
        raise HTTPException(status_code=404, detail="Proverb not found")
```
