# --description--

Add an optional query parameter `language` to `list_proverbs`: type `str | None`, default `None`. With no `language`, return every proverb. With it, return only the proverbs whose `language` is equal, so `GET /api/proverbs?language=Igbo` returns the two Igbo proverbs.

# --hints--

With no query, `GET /api/proverbs` should still return all 6 proverbs.

```py
r = await client.get('/api/proverbs')
assert len(r.json()) == 6
```

`GET /api/proverbs?language=Igbo` should return the 2 Igbo proverbs.

```py
r = await client.get('/api/proverbs', params={'language': 'Igbo'})
assert len(r.json()) == 2
assert all(p['language'] == 'Igbo' for p in r.json())
```

`GET /api/proverbs?language=Hausa` should return the 2 Hausa proverbs.

```py
r = await client.get('/api/proverbs', params={'language': 'Hausa'})
assert [p['id'] for p in r.json()] == [3, 4]
```

A language with no proverbs should give an empty list with status 200, not an error.

```py
r = await client.get('/api/proverbs', params={'language': 'Zulu'})
assert r.status_code == 200
assert r.json() == []
```

```python file=main.py
from fastapi import FastAPI, HTTPException

from proverbs import PROVERBS

app = FastAPI(title="Proverbs API")


def find_proverb(proverb_id: int):
    for proverb in PROVERBS:
        if proverb["id"] == proverb_id:
            return proverb
    return None


@app.get("/api/health")
def health():
    return {"status": "ok"}


@app.get("/api/proverbs")
def list_proverbs(language: str | None = None):
    if language is None:
        return PROVERBS
    return [p for p in PROVERBS if p["language"] == language]


@app.get("/api/proverbs/{proverb_id}")
def get_proverb(proverb_id: int):
    proverb = find_proverb(proverb_id)
    if proverb is None:
        raise HTTPException(status_code=404, detail="Proverb not found")
    return proverb
```

## --hint--

A function argument that is not in the path is a query parameter. Giving it the default `None` makes it optional.

## --hint--

Write `language: str | None = None`. If it is `None`, return `PROVERBS`. Otherwise return a list comprehension that keeps the proverbs whose `p["language"]` equals `language`.

## --hint--

Replace the two lines with:

```python
def list_proverbs(language: str | None = None):
    if language is None:
        return PROVERBS
    return [p for p in PROVERBS if p["language"] == language]
```
