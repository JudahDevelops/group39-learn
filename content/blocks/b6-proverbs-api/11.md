# --description--

To read a JSON body you need a Pydantic model. Below the `fastapi` import, import `BaseModel` and `Field` from `pydantic`.

# --hints--

Your code should import `BaseModel` and `Field` from `pydantic`.

```py
assert defines('BaseModel') and defines('Field')
```

`BaseModel` and `Field` should come from `pydantic`.

```py
import main, pydantic
assert main.BaseModel is pydantic.BaseModel
assert main.Field is pydantic.Field

from proverbs import PROVERBS

app = FastAPI(title="Proverbs API")


def find_proverb(proverb_id: int):
    for proverb in PROVERBS:
        if proverb["id"] == proverb_id:
            return proverb
    return None


@app.get("/api/health")
def health():
    return {"status": "ok"}


@app.get("/api/proverbs")
def list_proverbs(language: str | None = None):
    if language is None:
        return PROVERBS
    return [p for p in PROVERBS if p["language"].lower() == language.lower()]


@app.get("/api/proverbs/{proverb_id}")
def get_proverb(proverb_id: int):
    proverb = find_proverb(proverb_id)
    if proverb is None:
        raise HTTPException(status_code=404, detail="Proverb not found")
    return proverb
```

# --help--

## --hint--

A Pydantic model is a class. The class you extend is called `BaseModel`, and `Field` adds rules to a field. Both live in the `pydantic` module.

## --hint--

The import has the shape `from pydantic import ..., ...`, with the two names separated by a comma.

## --hint--

Type `from pydantic import BaseModel, Field` on the empty line.
