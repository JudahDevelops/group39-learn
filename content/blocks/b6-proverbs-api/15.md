# --description--

At the moment a proverb with the text `Hi` is accepted. Make `text` need at least 10 characters: give it the value `Field(min_length=10)` in `ProverbIn`.

# --hints--

A proverb with the text `Hi` should be refused with status 422.

```py
r = await client.post('/api/proverbs', json={'text': 'Hi', 'language': 'Igbo', 'meaning': 'A greeting'})
assert r.status_code == 422
```

A body with no `meaning` should be refused with status 422.

```py
r = await client.post('/api/proverbs', json={'text': 'Let the kite perch and let the eagle perch.', 'language': 'Igbo'})
assert r.status_code == 422
```

A proper proverb should still be accepted with status 201.

```py
r = await client.post('/api/proverbs', json={"text": "Let the kite perch and let the eagle perch.", "language": "Igbo", "meaning": "Live and let live: there is room for everyone."})
assert r.status_code == 201
```

# --help--

## --hint--

`Field` adds rules to a field. The rule for the shortest text is called `min_length`.

## --hint--

A field with a rule is written `name: type = Field(rule)`. For `text` that is `text: str = Field(min_length=10)`.

## --hint--

Replace the `text` line with:

```python
    text: str = Field(min_length=10)
```
