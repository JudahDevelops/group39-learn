# --description--

The same proverb should not be added twice. In `create_proverb`, before the new dictionary is built, loop through `PROVERBS`. If a proverb has the same `text`, raise an `HTTPException` with status code 409 and the detail `That proverb is already in the list`.

# --hints--

Adding a proverb whose `text` is already in the list should answer with status 409.

```py
first = (await client.get('/api/proverbs')).json()[0]
r = await client.post('/api/proverbs', json={'text': first['text'], 'language': first['language'], 'meaning': first['meaning']})
assert r.status_code == 409
```

The 409 reply should have the detail `That proverb is already in the list`.

```py
first = (await client.get('/api/proverbs')).json()[0]
r = await client.post('/api/proverbs', json={'text': first['text'], 'language': first['language'], 'meaning': first['meaning']})
assert r.json()['detail'] == 'That proverb is already in the list'
```

A refused proverb should not be stored. The list should keep the same length.

```py
before = len((await client.get('/api/proverbs')).json())
first = (await client.get('/api/proverbs')).json()[0]
await client.post('/api/proverbs', json={'text': first['text'], 'language': first['language'], 'meaning': first['meaning']})
assert len((await client.get('/api/proverbs')).json()) == before
```

A new proverb should be accepted once with 201, and refused with 409 the second time.

```py
sent = {'text': 'A toad does not run in the daytime for nothing.', 'language': 'Igbo', 'meaning': 'When something unusual happens, there is always a reason.'}
first = await client.post('/api/proverbs', json=sent)
second = await client.post('/api/proverbs', json=sent)
assert first.status_code == 201
assert second.status_code == 409
```

```python file=main.py
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

from proverbs import PROVERBS

app = FastAPI(title="Proverbs API")


class ProverbIn(BaseModel):
    text: str = Field(min_length=10)
    language: str
    meaning: str


def next_id() -> int:
    highest = 0
    for proverb in PROVERBS:
        if proverb["id"] > highest:
            highest = proverb["id"]
    return highest + 1


def find_proverb(proverb_id: int):
    for proverb in PROVERBS:
        if proverb["id"] == proverb_id:
            return proverb
    return None


@app.get("/api/health")
def health():
    return {"status": "ok"}


@app.get("/api/proverbs")
def list_proverbs(language: str | None = None):
    if language is None:
        return PROVERBS
    return [p for p in PROVERBS if p["language"].lower() == language.lower()]


@app.get("/api/proverbs/{proverb_id}")
def get_proverb(proverb_id: int):
    proverb = find_proverb(proverb_id)
    if proverb is None:
        raise HTTPException(status_code=404, detail="Proverb not found")
    return proverb


@app.post("/api/proverbs", status_code=201)
def create_proverb(body: ProverbIn):
    for proverb in PROVERBS:
        if proverb["text"] == body.text:
            raise HTTPException(status_code=409, detail="That proverb is already in the list")
    proverb = {
        "id": next_id(),
        "text": body.text,
        "language": body.language,
        "meaning": body.meaning,
    }
    PROVERBS.append(proverb)
    return proverb
```

## --hint--

A conflict is a request that clashes with what is already stored. The status code for it is 409, as in the table of status codes.

## --hint--

Loop through `PROVERBS` and compare `proverb["text"]` with `body.text`. Raise the exception inside the `if`, before the new dictionary is built.

```python
    for proverb in PROVERBS:
```
