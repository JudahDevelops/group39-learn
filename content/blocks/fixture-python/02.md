# --description--

Add a function called `compute_deadline` that takes `urgency` and returns how many hours a complaint may stay open. An `"urgent"` complaint gets 24 hours, a `"normal"` one gets 72 hours and a `"low"` one gets 168 hours.

# --hints--

Your code should define a function called `compute_deadline`.

```py
assert has_function('compute_deadline')
```

`compute_deadline("urgent")` should return `24`.

```py
assert compute_deadline('urgent') == 24
```

`compute_deadline("normal")` should return `72`.

```py
assert compute_deadline('normal') == 72
```

`compute_deadline("low")` should return `168`.

```py
assert compute_deadline('low') == 168
```

# --solutions--

```python file=main.py
# Notice for the hall board
print("Water is off in Hall A today.")

def compute_deadline(urgency):
    if urgency == "urgent":
        return 24
    elif urgency == "normal":
        return 72
    else:
        return 168
```
