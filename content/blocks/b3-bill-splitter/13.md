# --description--

`.value` is always text, even in a number field. Wrap it in `Number()` so that `total` is a real number you can calculate with.

# --hints--

Your `total` should be a number. Clicking with `4500` in the bill field should log the number `4500`, not the text.

```js
const calls = [];
const real = console.log;
console.log = (...args) => calls.push(args);
try {
  document.querySelector('#bill').value = '4500';
  document.querySelector('#split').click();
} finally { console.log = real; }
assert.isTrue(calls.flat().includes(4500));
```
