# --help--

## --hint--

`document.querySelector` takes a CSS selector in quotation marks and gives back the first element that matches.

## --hint--

An id selector starts with `#`. The input for the bill has the id `bill`, so its selector is `"#bill"`.

## --hint--

Type `const billInput = document.querySelector("#bill");` and, on the next line, `const peopleInput = document.querySelector("#people");`.
