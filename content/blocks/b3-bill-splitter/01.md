# --description--

In this workshop you will build a bill splitter for friends who eat out. The page, `splitter.html`, is already written. The code goes in `script.js`, which is empty for now.

First, connect the two. At the end of the `head`, add a `script` element with `src` set to `script.js` and the `defer` attribute, so the script waits until the page has loaded.

# --hints--

Your `head` element should have a `script` element.

```js
assert.match(code, /<head[\s>][\s\S]*<script[\s>][\s\S]*<\/head\s*>/i);
```

Your `script` element should have the attribute `src="script.js"`. Check the spelling of the file name.

```js
assert.match(code, /<script\s[^>]*src\s*=\s*("|')(?:\.\/)?script\.js\1[^>]*>/i);
```

Your `script` element should have the `defer` attribute.

```js
assert.match(code, /<script\s[^>]*\bdefer\b[^>]*>/i);
```

A `script` element needs a closing tag: `</script>`.

```js
assert.match(code, /<\/script\s*>/i);
```

# --help--

## --hint--

A `script` element loads a JavaScript file, much as a `link` element loads a stylesheet. The `defer` attribute makes the script wait for the page.

## --hint--

Write `<script`, then the attribute `src="script.js"`, then `defer`, then `></script>`. Unlike `link`, a `script` element has a closing tag.

## --hint--

Type `<script src="script.js" defer></script>` on the empty line.
