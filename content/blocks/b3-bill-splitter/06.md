# --description--

Put the sum in a function you can reuse. Below the first log, write a function `splitBill` with two parameters, `total` and `count`. It should return `total` divided by `count`, rounded to the nearest naira.

# --hints--

Your code should define a function called `splitBill`.

```js
assert.isFunction(splitBill);
```

`splitBill(10000, 4)` should return `2500`. Use `return` to give the answer back.

```js
assert.strictEqual(splitBill(10000, 4), 2500);
```

`splitBill(25000, 3)` should return `8333`. Round the result with `Math.round()`.

```js
assert.strictEqual(splitBill(25000, 3), 8333);
```

`splitBill(2000, 3)` should return `667`, because 666.67 rounds to the nearest naira.

```js
assert.strictEqual(splitBill(2000, 3), 667);
```
