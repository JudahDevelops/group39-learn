# --description--

Each share is rounded, so the shares may not add up to the bill. ₦25000 shared by 3 gives ₦8333 each, which is ₦24999 together. Show that in the `together` paragraph: set `together.textContent` to `Together the shares add up to ₦${share * count}`.

# --hints--

Clicking with `25000` and `3` in the fields should show `Together the shares add up to ₦24999` in the `together` paragraph.

```js
document.querySelector('#bill').value = '25000';
document.querySelector('#people').value = '3';
document.querySelector('#split').click();
assert.equal(document.querySelector('#together').textContent.trim(), 'Together the shares add up to ₦24999');
```

Clicking with `10000` and `4` in the fields should show `Together the shares add up to ₦10000`.
