# --description--

Start with a sample bill. Below the log, create two variables with `const`: `bill` set to `25000` and `people` set to `3`. The amount is in naira. A number is written without quotation marks.

# --hints--

Your code should have a `const` variable called `bill` set to the number `25000`.

```js
assert.match(files['script.js'], /\bconst\s+bill\b/);
assert.strictEqual(bill, 25000);
```

Your code should have a `const` variable called `people` set to the number `3`.

```js
assert.match(files['script.js'], /\bconst\s+people\b/);
assert.strictEqual(people, 3);
```

# --help--

## --hint--

A `const` variable has a name and a value, joined by `=`. Write the number with no quotation marks.

## --hint--

Write `const bill = ` and the number, then a semicolon. Do the same for `people` on the next line.

## --hint--

Type `const bill = 25000;` and, on the next line, `const people = 3;`.
