# --description--

Handle an empty bill. An empty field gives the empty text, and `Number("")` is `0`, so one check catches an empty bill and a zero bill. Below `count`, add an `if` that runs when `total <= 0`. Inside it, set `result.textContent` to `Enter a bill total above zero.`, set `together.textContent` to `""`, and `return`, which ends the function early.

# --hints--

With an empty bill field, the `result` paragraph should say `Enter a bill total above zero.`

```js
document.querySelector('#bill').value = '';
document.querySelector('#people').value = '3';
document.querySelector('#split').click();
assert.equal(document.querySelector('#result').textContent.trim(), 'Enter a bill total above zero.');
```

With a bill of `0`, the `result` paragraph should say `Enter a bill total above zero.`

```js
document.querySelector('#bill').value = '0';
document.querySelector('#people').value = '3';
document.querySelector('#split').click();
assert.equal(document.querySelector('#result').textContent.trim(), 'Enter a bill total above zero.');
```

The message should replace an old total. After a good split and then an empty bill, the `together` paragraph should be empty.

```js
document.querySelector('#bill').value = '25000';
document.querySelector('#people').value = '3';
document.querySelector('#split').click();
document.querySelector('#bill').value = '';
document.querySelector('#split').click();
assert.equal(document.querySelector('#together').textContent.trim(), '');
```

A good bill should still show its share. `25000` shared by `3` should show `Each person pays ₦8333`.

```js
document.querySelector('#bill').value = '25000';
document.querySelector('#people').value = '3';
document.querySelector('#split').click();
assert.equal(document.querySelector('#result').textContent.trim(), 'Each person pays ₦8333');
```

# --solutions--

```js file=script.js
console.log("Bill Splitter ready");

function splitBill(total, count) {
  return Math.round(total / count);
}

const billInput = document.querySelector("#bill");
const peopleInput = document.querySelector("#people");
const splitButton = document.querySelector("#split");
const result = document.querySelector("#result");
const together = document.querySelector("#together");

function showShare() {
  const total = Number(billInput.value);
  const count = Number(peopleInput.value);

  if (total <= 0) {
    result.textContent = "Enter a bill total above zero.";
    together.textContent = "";
    return;
  }

  const share = splitBill(total, count);
  result.textContent = `Each person pays ₦${share}`;
  together.textContent = `Together the shares add up to ₦${share * count}`;
}

splitButton.addEventListener("click", showShare);
```

## --hint--

An `if` block runs only when its condition is true. `return` ends the function, so the lines below it are skipped.

## --hint--

Write `if (total <= 0) {`, then the two lines that set the message and clear `together`, then `return;` and `}`.
