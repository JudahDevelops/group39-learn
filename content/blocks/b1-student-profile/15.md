# --description--

Add a second section to the page. Inside `main`, below the list, add an `h2` element with the text `My courses this semester`.

# --hints--

Your `main` element should have a second `h2` element, below the list.

```js
assert.lengthOf(document.querySelectorAll('main > h2'), 2);
```

Your new `h2` element needs a closing tag, `</h2>`, with a `/` just after the `<`.

```js
assert.lengthOf(code.match(/<\/h2\s*>/gi) ?? [], 2);
```

Your new `h2` element should come right below the `ul` element, inside `main`.

```js
assert.strictEqual(document.querySelector('main > ul').nextElementSibling, document.querySelectorAll('main > h2')[1]);
```

Your new `h2` element should have the text `My courses this semester`. Check the spelling and the capital letter.

```js
assert.equal(document.querySelectorAll('main > h2')[1]?.textContent.trim(), 'My courses this semester');
```
