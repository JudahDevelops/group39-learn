# --description--

A `tbody` element holds the data rows. Inside the `table`, below the `thead`, add a `tbody` element. Inside it, add one `tr` row with three `td` cells: `COS 311`, `Data Structures` and `3`.

# --hints--

Your `table` element should have a `tbody` element. Its opening tag is `<tbody>`.

```js
assert.match(code, /<tbody[\s>]/i);
```

Your `tbody` element needs a closing tag, `</tbody>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/tbody\s*>/i);
```

Your `tbody` element should come right below the `thead` element, inside the `table`.

```js
assert.strictEqual(document.querySelector('thead').nextElementSibling, document.querySelector('tbody'));
```

Your `tbody` element should have one row, a `tr` element, and the row needs a closing tag, `</tr>`.

```js
assert.lengthOf(document.querySelectorAll('tbody > tr'), 1);
assert.lengthOf(code.match(/<\/tr\s*>/gi) ?? [], 2);
```

Your row should have three `td` cells, and each needs a closing tag, `</td>`.

```js
assert.lengthOf(document.querySelectorAll('tbody td'), 3);
assert.lengthOf(code.match(/<\/td\s*>/gi) ?? [], 3);
```

Your three `td` cells should have the text `COS 311`, `Data Structures` and `3`, in that order. Check the spelling.

```js
const cells = [...document.querySelectorAll('tbody td')].map((td) => td.textContent.trim());
assert.deepEqual(cells, ['COS 311', 'Data Structures', '3']);
```
