# --description--

An `img` element shows a picture. Between the `h1` and the `p`, add an `img` element. Set its `src` attribute to `/img/amina-bello.svg`, and give it an `alt` attribute that describes the picture in words. An `img` has no closing tag.

# --hints--

Your page should have an `img` element between the `h1` element and the `p` element.

```js
const img = document.querySelector('img');
assert.exists(img);
assert.strictEqual(document.querySelector('h1').nextElementSibling, img);
assert.strictEqual(img.nextElementSibling, document.querySelector('p'));
```

Your `img` element should have the attribute `src="/img/amina-bello.svg"`. Check the spelling of the file name.

```js
assert.equal(document.querySelector('img')?.getAttribute('src'), '/img/amina-bello.svg');
```

Your `img` element needs an `alt` attribute that describes the picture in words, not just the file name.

```js
const alt = document.querySelector('img')?.getAttribute('alt') ?? '';
assert.isAbove(alt.trim().length, 0);
assert.notMatch(alt, /\.svg/i);
```

An `img` element has no closing tag. Remove any `</img>`.

```js
assert.notMatch(code, /<\/img\s*>/i);
```

# --help--

## --hint--

An `img` element has two attributes that matter: one says which file to show, the other describes the picture for people who cannot see it.

## --hint--

The attributes are `src="..."` for the file and `alt="..."` for the description. Both go inside one opening tag, `<img>`.

## --hint--

Type `<img src="/img/amina-bello.svg" alt="Head and shoulders of a student with a gold ID tag">` on the empty line.
