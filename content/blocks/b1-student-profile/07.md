# --description--

A link is an `a` element. Its `href` attribute says which file it opens. Below the paragraph, add a link to the Student Portal page. Set `href` to `student.html` and give the link the text `Student Portal`.

# --hints--

Your page should have an `a` element below the `p` element. Its opening tag is `<a>`.

```js
const p = document.querySelector('p');
const a = document.querySelector('a');
assert.exists(a);
assert.isTrue(Boolean(p.compareDocumentPosition(a) & Node.DOCUMENT_POSITION_FOLLOWING));
```

Your `a` element needs a closing tag, `</a>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/a\s*>/i);
```

Your `a` element should have the attribute `href="student.html"`. Put the value in quotation marks inside the opening tag.

```js
assert.equal(document.querySelector('a')?.getAttribute('href'), 'student.html');
```

Your `a` element should have the text `Student Portal`. The text goes between the opening and closing tags.

```js
assert.equal(document.querySelector('a')?.textContent.trim(), 'Student Portal');
```

# --help--

## --hint--

A link needs two things: the text people read, and the file it opens. The file goes in an attribute inside the opening tag.

## --hint--

The tags are `<a>` and `</a>`. The attribute is written `href="file name"`, after the `a` in the opening tag.

## --hint--

Type `<a href="student.html">Student Portal</a>` on the empty line.
