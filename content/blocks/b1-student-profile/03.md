# --description--

Everything a visitor sees goes in the `body` element. Inside the `html` element, add a `body` element. Inside the `body`, add an `h1` element with the text `Amina Bello`. An `h1` is the main heading of a page. Your first heading now shows in the preview.

# --hints--

Your `html` element should contain a `body` element with an opening tag, `<body>`, and a closing tag, `</body>`.

```js
assert.match(code, /<html[^>]*>[\s\S]*<body[^>]*>[\s\S]*<\/body\s*>[\s\S]*<\/html\s*>/i);
```

Your `body` element should contain an `h1` element. Its opening tag is `<h1>`.

```js
assert.match(code, /<body[^>]*>[\s\S]*<h1[\s>][\s\S]*<\/body\s*>/i);
```

Your `h1` element needs a closing tag, `</h1>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/h1\s*>/i);
```

Your `h1` element should have the text `Amina Bello`. Check the spelling, and make sure the text sits between the opening and closing tags.

```js
assert.equal(document.querySelector('body > h1')?.textContent.trim(), 'Amina Bello');
```

# --help--

## --hint--

The `body` element goes inside the `html` element, and the `h1` element goes inside the `body` element. Elements sit inside each other like boxes.

## --hint--

The tags are `<body>` and `</body>`, and `<h1>` and `</h1>`. The text goes between `<h1>` and `</h1>`.

## --hint--

Type `<body>` on the first empty line, `<h1>Amina Bello</h1>` below it, and `</body>` below that.
