# --description--

A `table` element shows data in rows and columns. Below the new `h2`, add a `table` element. Inside it, add a `thead` element with one `tr` row of three `th` header cells: `Code`, `Course` and `Units`.

# --hints--

Your page should have a `table` element. Its opening tag is `<table>`.

```js
assert.match(code, /<table[\s>]/i);
```

Your `table` element needs a closing tag, `</table>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/table\s*>/i);
```

Your `table` element should come right below the `My courses this semester` heading, inside `main`.

```js
assert.strictEqual(document.querySelectorAll('main > h2')[1].nextElementSibling, document.querySelector('main > table'));
```

Your `table` element should have a `thead` element that holds one row, a `tr` element.

```js
assert.exists(document.querySelector('table > thead > tr'));
```

Your `thead` and `tr` elements need closing tags, `</thead>` and `</tr>`.

```js
assert.match(code, /<\/thead\s*>/i);
assert.match(code, /<\/tr\s*>/i);
```

Your header row should have three `th` cells, and each needs a closing tag, `</th>`.

```js
assert.lengthOf(document.querySelectorAll('thead th'), 3);
assert.lengthOf(code.match(/<\/th\s*>/gi) ?? [], 3);
```

Your three `th` cells should have the text `Code`, `Course` and `Units`, in that order. Check the spelling.

```js
const heads = [...document.querySelectorAll('thead th')].map((th) => th.textContent.trim());
assert.deepEqual(heads, ['Code', 'Course', 'Units']);
```

# --help--

## --hint--

A table is built from the outside in: the table, then a group of rows, then a row, then its cells.

## --hint--

Inside `<table>`, write `<thead>`, then `<tr>`, then three `<th>` cells. Then close each element in the opposite order.

## --hint--

Type `<table>`, `<thead>` and `<tr>`, then `<th>Code</th>`, `<th>Course</th>` and `<th>Units</th>`, then `</tr>`, `</thead>` and `</table>`.
