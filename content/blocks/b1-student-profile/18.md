# --description--

Your `tbody` element should have three rows. Each row is a `tr` element.

```js
assert.lengthOf(document.querySelectorAll('tbody > tr'), 3);
```

Each row needs a closing tag, `</tr>`, with a `/` just after the `<`.

```js
assert.lengthOf(code.match(/<\/tr\s*>/gi) ?? [], 4);
```

Each row should have three `td` cells, one for each heading, and each cell needs a closing tag, `</td>`.

```js

assert.lengthOf(code.match(/<\/td\s*>/gi) ?? [], 9);
```

Your second row should have the text `COS 313`, `Database Systems` and `3`, in that order. Check the spelling.

```js
const rows = [...document.querySelectorAll('tbody > tr')].map((tr) => [...tr.querySelectorAll('td')].map((td) => td.textContent.trim()));
assert.deepEqual(rows[1], ['COS 313', 'Database Systems', '3']);
```

Your third row should have the text `MTH 301`, `Linear Algebra` and `2`, in that order. Check the spelling.

```js
const rows = [...document.querySelectorAll('tbody > tr')].map((tr) => [...tr.querySelectorAll('td')].map((td) => td.textContent.trim()));
```
