# --description--

The `head` element holds information about the page. Above the `body`, add a `head` element. Inside it, add two `meta` elements. The first, `<meta charset="UTF-8">`, lets the page show symbols such as ₦. The second makes the page fit a phone screen:

`<meta name="viewport" content="width=device-width, initial-scale=1">`

# --hints--

Your `html` element should contain a `head` element above the `body` element, with an opening tag, `<head>`, and a closing tag, `</head>`.

```js
assert.match(code, /<head[\s>][\s\S]*<\/head\s*>[\s\S]*<body[\s>]/i);
```

Your `head` element should contain a `meta` element with the attribute `charset="UTF-8"`.

```js
const meta = document.querySelector('head > meta[charset]');
assert.exists(meta);
assert.equal(meta.getAttribute('charset').toUpperCase(), 'UTF-8');
```

Your `head` element should contain a `meta` element with `name="viewport"` and `content="width=device-width, initial-scale=1"`.

```js
const meta = document.querySelector('head > meta[name="viewport"]');
assert.exists(meta);
assert.equal(meta.getAttribute('content').replace(/\s+/g, ' ').trim(), 'width=device-width, initial-scale=1');
```

A `meta` element has no closing tag. Remove any `</meta>`.

```js
assert.notMatch(code, /<\/meta\s*>/i);
```

# --solutions--

```html file=index.html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
  </head>
  <body>
    <h1>Amina Bello</h1>
  </body>
</html>
```

# --help--

## --hint--

The `head` element sits beside the `body` element, above it, and both are inside the `html` element. Some elements, such as `meta`, have no closing tag.

## --hint--

Write `<head>` and `</head>`, then put the two `meta` lines between them. Each `meta` line is one opening tag with its attributes.

## --hint--

Type `<head>`, then `<meta charset="UTF-8">`, then the viewport line from the instructions, then `</head>`, each on its own line.
