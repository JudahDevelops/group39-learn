# --description--

A comment is a note for people that the browser ignores. Between the `header` and the `main`, add a comment with the text `Page content starts here`. A comment starts with `<!--` and ends with `-->`.

# --hints--

Your page should have a comment. It starts with `<!--`.

```js
assert.match(code, /<!--/);
```

Your comment needs an ending, `-->`. Without it, the browser treats the rest of the page as part of the comment.

```js
assert.match(code, /<!--[\s\S]*?-->/);
```

Your comment should have the text `Page content starts here`. Check the spelling and the capital letter.

```js
assert.match(code, /<!--\s*Page content starts here\s*-->/);
```

Your comment should be between the `header` and the `main`, just above the `main` element.

```js
assert.match(code, /<\/header\s*>\s*<!--\s*Page content starts here\s*-->\s*<main[\s>]/i);
```

Your `main` element should still be on the page. If it has vanished, the comment is missing its ending, `-->`.

```js
assert.exists(document.querySelector('main'));
assert.notInclude(document.body.textContent, 'Page content starts here');
```

# --help--

## --hint--

A comment is not an element, so it has no tag name. It has its own markers to show where it starts and ends.

## --hint--

A comment starts with `<!--` and ends with `-->`. The note goes between them.

## --hint--

Type `<!-- Page content starts here -->` on the empty line.
