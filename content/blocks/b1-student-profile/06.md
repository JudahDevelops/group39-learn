# --description--

A `p` element holds a paragraph of text. Below the `h1` element, add a `p` element with this text:

`Amina Bello is a 300 level Computer Science student in room B-214.`

# --hints--

Your `body` element should contain a `p` element. Its opening tag is `<p>`.

```js
assert.exists(document.querySelector('body > p'));
```

Your `p` element needs a closing tag, `</p>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/p\s*>/i);
```

Your `p` element should come below the `h1` element. You have them in the wrong order.

```js
const h1 = document.querySelector('h1');
const p = document.querySelector('p');
assert.isTrue(Boolean(h1.compareDocumentPosition(p) & Node.DOCUMENT_POSITION_FOLLOWING));
```

Your `p` element should have the text `Amina Bello is a 300 level Computer Science student in room B-214.` You have either left out some words or made a typo.

```js
const text = document.querySelector('p')?.textContent.replace(/\s+/g, ' ').trim();
assert.equal(text, 'Amina Bello is a 300 level Computer Science student in room B-214.');
```

## --hint--

A paragraph is its own element, separate from a heading. Its name is a single letter.

## --hint--

The tags are `<p>` and `</p>`. Put the sentence between them, on the line after the `h1` element.

## --hint--

Type `<p>Amina Bello is a 300 level Computer Science student in room B-214.</p>` on the empty line.
