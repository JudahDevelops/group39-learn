# --description--

A `nav` element holds the links that take a visitor around the site. Inside the `header`, put a `nav` element around the link.

# --hints--

Your page should have a `nav` element. Its opening tag is `<nav>`.

```js
assert.match(code, /<nav[\s>]/i);
```

Your `nav` element needs a closing tag, `</nav>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/nav\s*>/i);
```

Your `nav` element should be inside the `header` element.

```js
assert.exists(document.querySelector('header > nav'));
```

Your `nav` element should contain the link to `student.html`. Move the `a` element between the `nav` tags.

```js
assert.exists(document.querySelector('nav > a[href="student.html"]'));
```

Your page should have just one link, the one inside the `nav`. Remove any extra copy.

```js
assert.lengthOf(document.querySelectorAll('a'), 1);
```

# --solutions--

```html file=profile.html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Student Profile</title>
  </head>
  <body>
    <header>
      <h1>Amina Bello</h1>
      <img src="/img/amina-bello.svg" alt="Head and shoulders of a student with a gold ID tag">
      <p>Amina Bello is a 300 level Computer Science student in room B-214.</p>
      <nav>
        <a href="student.html">Student Portal</a>
      </nav>
    </header>
    <h2>About me</h2>
    <ul>
      <li>Football</li>
      <li>Cooking jollof rice</li>
      <li>Building web pages</li>
    </ul>
  </body>
</html>
```

# --help--

## --hint--

The `nav` element is another box. It sits inside the `header`, and it goes around the link.

## --hint--

The tags are `<nav>` and `</nav>`. The `a` element goes between them.

## --hint--

Type `<nav>` on the empty line above the link and `</nav>` on the empty line below it.
