# --description--

A `footer` element holds the bottom of a page. Below the `main` element, add a `footer` element. Inside it, add a `p` element with the text `Page made by Amina Bello.`

# --hints--

Your page should have a `footer` element. Its opening tag is `<footer>`.

```js
assert.match(code, /<footer[\s>]/i);
```

Your `footer` element needs a closing tag, `</footer>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/footer\s*>/i);
```

Your `footer` element should come right below the `main` element, not inside it.

```js
assert.strictEqual(document.querySelector('main').nextElementSibling, document.querySelector('footer'));
```

Your `footer` element should contain a `p` element.

```js
assert.exists(document.querySelector('footer > p'));
```

Your `p` element should have the text `Page made by Amina Bello.` Check the spelling and the full stop.

```js
assert.equal(document.querySelector('footer > p')?.textContent.trim(), 'Page made by Amina Bello.');
```
