# --description--

In this workshop you will build a profile page for Amina Bello, a 300 level Computer Science student in room B-214.

Every page starts with a line that tells the browser it is reading HTML. It is called the doctype. Type `<!DOCTYPE html>` on the first line. The preview stays blank for now, because a doctype shows nothing.

# --hints--

Your page needs the doctype `<!DOCTYPE html>`.

```js
assert.match(code, /<!DOCTYPE html>/i);
```

Your doctype should be the first line of the page.

```js
assert.match(code.trim(), /^<!DOCTYPE html>/i);
```

# --help--

## --hint--

The doctype is one line. It starts with `<!` and ends with `>`, and it shows nothing on the page.

## --hint--

Inside the `<!` and `>` you write the word `DOCTYPE`, a space, and then `html`.

## --hint--

Type `<!DOCTYPE html>` on the empty line.
