# --description--

A `main` element holds the content that belongs to this page alone. Below the `header`, put a `main` element around the `h2` and the `ul`.

# --hints--

Your page should have a `main` element. Its opening tag is `<main>`.

```js
assert.match(code, /<main[\s>]/i);
```

Your `main` element needs a closing tag, `</main>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/main\s*>/i);
```

Your `main` element should come right below the `header` element, not inside it.

```js
assert.strictEqual(document.querySelector('header').nextElementSibling, document.querySelector('main'));
```

Your `main` element should contain the `h2` element with the text `About me`.

```js
assert.equal(document.querySelector('main > h2')?.textContent.trim(), 'About me');
```

Your `main` element should contain the `ul` element with its three `li` items.

```js
assert.lengthOf(document.querySelectorAll('main > ul > li'), 3);
```
