# --description--

A `ul` element is a bulleted list, and each item in it is an `li` element. Below the `h2`, add a `ul` element with three `li` items: `Football`, `Cooking jollof rice` and `Building web pages`.

# --hints--

Your page should have a `ul` element. Its opening tag is `<ul>`.

```js
assert.exists(document.querySelector('ul'));
```

Your `ul` element needs a closing tag, `</ul>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/ul\s*>/i);
```

Your `ul` element should come below the `h2` element. You have them in the wrong order.

```js
const h2 = document.querySelector('h2');
const ul = document.querySelector('ul');
assert.isTrue(Boolean(h2.compareDocumentPosition(ul) & Node.DOCUMENT_POSITION_FOLLOWING));
```

Your `ul` element should have exactly three items. Each item is an `li` element.

```js
assert.lengthOf(document.querySelectorAll('ul > li'), 3);
```

Each `li` element needs a closing tag, `</li>`, with a `/` just after the `<`.

```js
assert.lengthOf(code.match(/<\/li\s*>/gi) ?? [], 3);
```

Your three `li` elements should have the text `Football`, `Cooking jollof rice` and `Building web pages`, in that order. Check the spelling.

```js
const items = [...document.querySelectorAll('ul > li')].map((li) => li.textContent.trim());
assert.deepEqual(items, ['Football', 'Cooking jollof rice', 'Building web pages']);
```

# --help--

## --hint--

A bulleted list has two kinds of element: one that wraps the whole list, and one for each item.

## --hint--

The list is `<ul>` and `</ul>`. Each item goes between `<li>` and `</li>`, inside the list.

## --hint--

Type `<ul>` on the empty line, then the three `li` lines below it, then `</ul>`. The first item is `<li>Football</li>`.
