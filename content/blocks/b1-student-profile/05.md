# --description--

The `title` element sets the text shown in the browser tab. Inside the `head`, below the two `meta` elements, add a `title` element with the text `Student Profile`.

# --hints--

Your `head` element should contain a `title` element. Its opening tag is `<title>`.

```js
assert.match(code, /<head[\s>][\s\S]*<title[\s>][\s\S]*<\/head\s*>/i);
```

Your `title` element needs a closing tag, `</title>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/title\s*>/i);
```

Your `title` element should have the text `Student Profile`. Check the spelling and the capital letters.

```js
assert.equal(document.querySelector('head > title')?.textContent.trim(), 'Student Profile');
```

# --help--

## --hint--

The `title` is a normal element with an opening tag, some text and a closing tag. It belongs in the `head`, not the `body`.

## --hint--

The tags are `<title>` and `</title>`. The text goes between them.

## --hint--

Type `<title>Student Profile</title>` on the empty line.
