# --description--

An `h2` element is a second-level heading, used for a section of the page. Below the link, add an `h2` element with the text `About me`.

# --hints--

Your page should have an `h2` element. Its opening tag is `<h2>`.

```js
assert.exists(document.querySelector('h2'));
```

Your `h2` element needs a closing tag, `</h2>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/h2\s*>/i);
```

Your `h2` element should come below the link. You have them in the wrong order.

```js
const a = document.querySelector('a');
const h2 = document.querySelector('h2');
assert.isTrue(Boolean(a.compareDocumentPosition(h2) & Node.DOCUMENT_POSITION_FOLLOWING));
```

Your `h2` element should have the text `About me`. Check the spelling and the capital letters.

```js
assert.equal(document.querySelector('h2')?.textContent.trim(), 'About me');
```

# --help--

## --hint--

Headings come in six sizes, from `h1` to `h6`. A heading for a section of the page is one size down from the main heading.

## --hint--

The tags are `<h2>` and `</h2>`. The text goes between them, on the line below the link.

## --hint--

Type `<h2>About me</h2>` on the empty line.
