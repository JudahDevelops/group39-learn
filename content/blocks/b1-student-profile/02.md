# --description--

The `html` element wraps everything else on the page. Below the doctype, add an `html` element. Give its opening tag a `lang` attribute with the value `en`, which tells the browser the page is in English.

# --hints--

Your page should have an `html` element. Its opening tag is `<html>`.

```js
assert.match(code, /<html[\s>]/i);
```

Your `html` element should have the attribute `lang="en"`. Put the value in quotation marks inside the opening tag.

```js
assert.match(code, /<html\s[^>]*lang\s*=\s*("|')en\1[^>]*>/i);
```

Your `html` element needs a closing tag. Closing tags have a `/` just after the `<`.

```js
assert.match(code, /<\/html\s*>/i);
```

Your `html` element should come after the doctype.

```js
assert.match(code, /<!DOCTYPE html>\s*<html[\s>]/i);
```

# --help--

## --hint--

An element has an opening tag and a closing tag. The closing tag repeats the name with a `/` in front.

## --hint--

The opening tag is `<html lang="en">`. The attribute goes inside the tag, after the element name. The closing tag is `</html>`.

## --hint--

Type `<html lang="en">` on the first empty line and `</html>` on the line below it.
