# --description--

The scores live in a list of dictionaries. A dictionary holds the facts about one student, and the list holds the dictionaries. Below the heading, make a list called `students` with two dictionaries, each with a `"name"` and a `"score"`: Amina Bello with 78, then Chidi Okafor with 64.

# --hints--

Your code should have a variable called `students`.

```py
assert defines('students')
```

Your `students` variable should be a list. A list goes inside square brackets, `[ ]`.

```py
assert isinstance(students, list)
```

Your list should have two dictionaries, with a comma between them.

```py
assert len(students) == 2 and all(isinstance(s, dict) for s in students)
```

Each dictionary should have the keys `"name"` and `"score"`, and no others.

```py
assert all(set(s) == {'name', 'score'} for s in students)
```

The first student should be Amina Bello with a score of 78. Check the spelling of the name.

```py
assert students[0] == {'name': 'Amina Bello', 'score': 78}
```

The second student should be Chidi Okafor with a score of 64. Check the spelling of the name.

```py
assert students[1] == {'name': 'Chidi Okafor', 'score': 64}
```
