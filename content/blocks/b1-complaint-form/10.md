# --description--

A `button` element with `type="submit"` sends the form. Below the `textarea`, inside the `form`, add a `button` element with `type="submit"` and the text `Submit complaint`.

# --hints--

Your `form` element should contain a `button` element. Its opening tag is `<button>`.

```js
assert.exists(document.querySelector('form > button'));
```

Your `button` element needs a closing tag, `</button>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/button\s*>/i);
```

Your `button` element should have the attribute `type="submit"`. Put the value in quotation marks inside the opening tag.

```js
assert.equal(document.querySelector('form > button')?.getAttribute('type'), 'submit');
```

Your `button` element should have the text `Submit complaint`. Check the spelling and the capital letter.

```js
assert.equal(document.querySelector('form > button')?.textContent.trim(), 'Submit complaint');
```

Your `button` element should come right below the `textarea` element, inside the `form`.

```js
assert.strictEqual(document.querySelector('form > textarea').nextElementSibling, document.querySelector('form > button'));
```

# --help--

## --hint--

The button goes inside the `form`, below the `textarea`. Its `type` attribute says what it does when it is pressed.

## --hint--

The opening tag is `<button type="submit">` and the closing tag is `</button>`. The text goes between them.
