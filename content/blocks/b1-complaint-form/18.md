# --description--

A `main` element holds the content that belongs to this page alone. Below the `header`, put a `main` element around everything else in the `body`: the three `h2` headings, the two paragraphs, the form and the table.

# --hints--

Your page should have a `main` element. Its opening tag is `<main>`.

```js
assert.match(code, /<main[\s>]/i);
```

Your `main` element needs a closing tag, `</main>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/main\s*>/i);
```

Your `main` element should come right below the `header` element, not inside it.

```js
assert.strictEqual(document.querySelector('header').nextElementSibling, document.querySelector('main'));
```

Your `main` element should contain the three `h2` elements, with the text `Your room`, `Report a fault` and `Your complaints`.

```js
const heads = [...document.querySelectorAll('main > h2')].map((h) => h.textContent.trim());
assert.deepEqual(heads, ['Your room', 'Report a fault', 'Your complaints']);
```

Your `main` element should contain the two `p` elements and the `form` element.

```js
assert.lengthOf(document.querySelectorAll('main > p'), 2);
assert.exists(document.querySelector('main > form'));
```

Your `main` element should contain the `table` element.

```js
assert.exists(document.querySelector('main > table'));
```

Your `h1` element and your `nav` element should stay in the `header`, not inside `main`.

```js
assert.notExists(document.querySelector('main h1, main nav'));
```

# --help--

## --hint--

A `main` element wraps the part of the page that is not in the `header`. Everything from the first `h2` to the table goes inside it.

## --hint--

The opening tag is `<main>` and the closing tag is `</main>`. The `header` stays outside.

## --hint--

Type `<main>` on the line above the first `h2`, and `</main>` on the line below `</table>`.
