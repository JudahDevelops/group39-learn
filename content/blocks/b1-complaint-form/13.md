# --description--

A `tbody` element holds the data rows. Inside the `table`, below the `thead`, add a `tbody` element with one `tr` row of five `td` cells: `482`, `Plumbing`, `Urgent`, `24 hours` and `Open`.

This is Amina's complaint about water dripping onto a socket. She typed only the description. The system set the category, the urgency and the deadline.

# --hints--

Your `table` element should have a `tbody` element. Its opening tag is `<tbody>`.

```js
assert.match(code, /<tbody[\s>]/i);
```

Your `tbody` element needs a closing tag, `</tbody>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/tbody\s*>/i);
```

Your `tbody` element should come right below the `thead` element, inside the `table`.

```js
assert.strictEqual(document.querySelector('thead').nextElementSibling, document.querySelector('tbody'));
```

Your `tbody` element should have one row, a `tr` element, and the row needs a closing tag, `</tr>`.

```js
assert.lengthOf(document.querySelectorAll('tbody > tr'), 1);
assert.lengthOf(code.match(/<\/tr\s*>/gi) ?? [], 2);
```

Your row should have five `td` cells, and each needs a closing tag, `</td>`.

```js
assert.lengthOf(document.querySelectorAll('tbody td'), 5);
assert.lengthOf(code.match(/<\/td\s*>/gi) ?? [], 5);
```

Your five `td` cells should have the text `482`, `Plumbing`, `Urgent`, `24 hours` and `Open`, in that order. Check the spelling.

```js
const cells = [...document.querySelectorAll('tbody td')].map((td) => td.textContent.replace(/\s+/g, ' ').trim());
assert.deepEqual(cells, ['482', 'Plumbing', 'Urgent', '24 hours', 'Open']);
```

# --help--

## --hint--

The data rows go in their own group, below the header group and inside the `table`.

## --hint--

A `tbody` holds a `tr`. The `tr` holds five `td` cells, in the same order as the column headings.

## --hint--

Type `<tbody>` and `<tr>` on separate lines. Then type `<td>482</td><td>Plumbing</td><td>Urgent</td><td>24 hours</td><td>Open</td>`. Finish with `</tr>` and `</tbody>`, each on its own line.
