# --description--

A `p` element holds a paragraph of text. Below the `h2`, add a `p` element with the text `Room B-214`. This is the room Amina was allocated.

# --hints--

Your `body` element should contain a `p` element. Its opening tag is `<p>`.

```js
assert.exists(document.querySelector('body > p'));
```

Your `p` element needs a closing tag, `</p>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/p\s*>/i);
```

Your `p` element should come right below the `h2` element. You have them in the wrong order.

```js
assert.strictEqual(document.querySelector('h2').nextElementSibling, document.querySelector('p'));
```

Your `p` element should have the text `Room B-214`. Check the spelling and the capital letter.

```js
const text = document.querySelector('body > p')?.textContent.replace(/\s+/g, ' ').trim();
assert.equal(text, 'Room B-214');
```
