# --description--

A comment is a note for people that the browser ignores. The rows in the table are samples. Between the `h2` that says `Your complaints` and the `table`, add a comment with the text `Sample complaints only`. A comment starts with `<!--` and ends with `-->`.

# --hints--

Your page should have a comment. It starts with `<!--`.

```js
assert.match(code, /<!--/);
```

Your comment needs an ending, `-->`. Without it, the browser treats the rest of the page as part of the comment.

```js
assert.match(code, /<!--[\s\S]*?-->/);
```

Your comment should have the text `Sample complaints only`. Check the spelling and the capital letter.

```js
assert.match(code, /<!--\s*Sample complaints only\s*-->/);
```

Your comment should be between the `Your complaints` heading and the `table`, just above the `table` element.

```js
assert.match(code, /<h2>\s*Your complaints\s*<\/h2>\s*<!--\s*Sample complaints only\s*-->\s*<table[\s>]/i);
```

Your `table` element should still be on the page. If it has vanished, the comment is missing its ending, `-->`.

```js
assert.exists(document.querySelector('main > table'));
assert.notInclude(document.body.textContent, 'Sample complaints only');
```

# --help--

## --hint--

A comment is not an element, so it has no tag name. It has its own markers to show where it starts and ends.

## --hint--

A comment starts with `<!--` and ends with `-->`. The note goes between them.

## --hint--

Type `<!-- Sample complaints only -->` on the empty line.
