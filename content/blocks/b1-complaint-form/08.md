# --description--

A `textarea` element is a box for several lines of text. Below the label, add a `textarea` element with three attributes. `id="description"` matches the label's `for`, so clicking the label puts the cursor in the box. `name="description"` is the name the page uses for what is typed. `rows="4"` makes the box four lines tall.

# --hints--

Your `form` element should contain a `textarea` element. Its opening tag is `<textarea>`.

```js
assert.exists(document.querySelector('form > textarea'));
```

Your `textarea` element needs a closing tag, `</textarea>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/textarea\s*>/i);
```

Your `textarea` element should have the attribute `id="description"`. The label's `for` points to this `id`, so spell it the same.

```js
assert.equal(document.querySelector('form > textarea')?.getAttribute('id'), 'description');
```

Your `textarea` element should have the attribute `name="description"`.

```js
assert.equal(document.querySelector('form > textarea')?.getAttribute('name'), 'description');
```

Your `textarea` element should have the attribute `rows="4"`.

```js
assert.equal(document.querySelector('form > textarea')?.getAttribute('rows'), '4');
```

Your `textarea` element should come right below the `label` element. You have them in the wrong order.

```js
assert.strictEqual(document.querySelector('form > label').nextElementSibling, document.querySelector('form > textarea'));
```

# --help--

## --hint--

The `textarea` goes inside the `form`, below the label. It has three attributes: one that matches the label, one that names the data, and one that sets its height.

## --hint--

The attributes are `id`, `name` and `rows`. Put all three inside the opening tag. A `textarea` has a closing tag, and nothing between the tags yet.

## --hint--

Type `<textarea id="description" name="description" rows="4"></textarea>` on the empty line.
