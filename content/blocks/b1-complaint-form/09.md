# --description--

Amina must say what is wrong before she sends a complaint. Add the `required` attribute to the `textarea`. The browser will not send the form until the box has some text in it.

# --hints--

Your `textarea` element should have the attribute `required`. Write it inside the opening tag, with no value.

```js
assert.isTrue(document.querySelector('form > textarea')?.hasAttribute('required'));
```

Your `textarea` element should keep its `id`, `name` and `rows` attributes. Only add `required`.

```js
const textarea = document.querySelector('form > textarea');
assert.equal(textarea?.getAttribute('id'), 'description');
assert.equal(textarea?.getAttribute('name'), 'description');
assert.equal(textarea?.getAttribute('rows'), '4');
```

## --hint--

`required` is an attribute that has no value. It goes inside the opening tag of the `textarea`, beside the other attributes.

## --hint--

After `rows="4"`, add a space and then the word `required`. The `>` that ends the opening tag stays where it is.
