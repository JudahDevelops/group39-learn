# --description--

A `header` element holds the top of a page. Put a `header` element around the `h1`.

# --hints--

Your page should have a `header` element. Its opening tag is `<header>`.

```js
assert.exists(document.querySelector('header'));
```

Your `header` element needs a closing tag, `</header>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/header\s*>/i);
```

Your `header` element should contain the `h1` element.

```js
assert.exists(document.querySelector('header > h1'));
```

Your `header` element should come right above the `h2` element with the text `Your room`.

```js
assert.strictEqual(document.querySelector('header').nextElementSibling, document.querySelector('h2'));
```

Your headings, paragraphs, form and table should stay below the `header`, not inside it.

```js
assert.notExists(document.querySelector('header h2, header p, header form, header table'));
```

# --help--

## --hint--

The `header` wraps the `h1`. Put its opening tag above the `h1` and its closing tag below it.

## --hint--

The opening tag is `<header>` and the closing tag is `</header>`. The `h2` below the heading must stay outside.

## --hint--

Type `<header>` on the line above the `h1`, and `</header>` on the line below it.
