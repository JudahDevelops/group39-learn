# --description--

A `form` element wraps the fields and the button that send a complaint. Below the paragraph, add a `form` element. Give its opening tag an `id` attribute with the value `complaint-form`. An `id` is a name that only this element has on the page.

# --hints--

Your page should have a `form` element. Its opening tag is `<form>`.

```js
assert.exists(document.querySelector('form'));
```

Your `form` element needs a closing tag, `</form>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/form\s*>/i);
```

Your `form` element should have the attribute `id="complaint-form"`. Put the value in quotation marks inside the opening tag.

```js
assert.equal(document.querySelector('form')?.getAttribute('id'), 'complaint-form');
```

Your `form` element should come right below the paragraph about the category and the urgency, not inside it.

```js
assert.strictEqual(document.querySelectorAll('body > p')[1].nextElementSibling, document.querySelector('body > form'));
```

# --help--

## --hint--

A form is an element that holds other elements. Its opening tag carries an attribute that gives the form a name.

## --hint--

The opening tag is `<form id="complaint-form">` and the closing tag is `</form>`. Put the closing tag on its own line, below the opening tag.

## --hint--

Type `<form id="complaint-form">` on the empty line. On the line below it, type `</form>`.
