# --description--

An `h2` element is a second-level heading, used for a section of the page. Below the `h1`, add an `h2` element with the text `Your room`. It starts the first section.

# --hints--

Your `body` element should contain an `h2` element. Its opening tag is `<h2>`.

```js
assert.exists(document.querySelector('body > h2'));
```

Your `h2` element needs a closing tag, `</h2>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/h2\s*>/i);
```

Your `h2` element should come below the `h1` element. You have them in the wrong order.

```js
const h1 = document.querySelector('h1');
const h2 = document.querySelector('h2');
assert.isTrue(Boolean(h1.compareDocumentPosition(h2) & Node.DOCUMENT_POSITION_FOLLOWING));
```

Your `h2` element should have the text `Your room`. Check the spelling and the capital letter.

```js
assert.equal(document.querySelector('body > h2')?.textContent.trim(), 'Your room');
```

# --help--

## --hint--

An `h2` works like an `h1`, but it heads a section of the page, not the whole page.

## --hint--

The opening tag is `<h2>` and the closing tag is `</h2>`. It goes below the `h1`.

## --hint--

Type `<h2>Your room</h2>` on the empty line.
