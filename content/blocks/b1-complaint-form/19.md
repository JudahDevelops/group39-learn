# --description--

A `footer` element holds the bottom of a page. Below the `main` element, add a `footer` element. Inside it, add a `p` element with the text `Group 39 · COS 303 · Nile University of Nigeria`. Copy the text from this step, so that the dots are right.

# --hints--

Your page should have a `footer` element. Its opening tag is `<footer>`.

```js
assert.match(code, /<footer[\s>]/i);
```

Your `footer` element needs a closing tag, `</footer>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/footer\s*>/i);
```

Your `footer` element should come right below the `main` element, not inside it.

```js
assert.strictEqual(document.querySelector('main').nextElementSibling, document.querySelector('footer'));
```

Your `footer` element should contain a `p` element.

```js
assert.exists(document.querySelector('footer > p'));
```

Your `p` element should have the text `Group 39 · COS 303 · Nile University of Nigeria`. Check the spelling, and copy the dots from this step.

```js
const text = document.querySelector('footer > p')?.textContent.replace(/\s+/g, ' ').trim() ?? '';
assert.include(text, 'Group 39');
assert.include(text, 'COS 303');
assert.include(text, 'Nile University of Nigeria');
```
