# --description--

Inside the `nav`, add three more links. Together the four links should be, in order: `Home` to `index.html`, `Student Portal` to `student.html`, `Staff Dashboard` to `staff.html` and `Admin Dashboard` to `admin.html`.

# --hints--

Your `nav` element should have four links. Each link is an `a` element.

```js
assert.lengthOf(document.querySelectorAll('nav > a'), 4);
```

Each link needs a closing tag, `</a>`, with a `/` just after the `<`.

```js
assert.lengthOf(code.match(/<\/a\s*>/gi) ?? [], 4);
```

Your links should go to `index.html`, `student.html`, `staff.html` and `admin.html`, in that order. Check that each `href` has the file name spelled exactly.

```js
const hrefs = [...document.querySelectorAll('nav > a')].map((a) => a.getAttribute('href'));
assert.deepEqual(hrefs, ['index.html', 'student.html', 'staff.html', 'admin.html']);
```

Your links should have the text `Home`, `Student Portal`, `Staff Dashboard` and `Admin Dashboard`, in that order. Check the spelling.

```js
const texts = [...document.querySelectorAll('nav > a')].map((a) => a.textContent.trim());
assert.deepEqual(texts, ['Home', 'Student Portal', 'Staff Dashboard', 'Admin Dashboard']);
```
