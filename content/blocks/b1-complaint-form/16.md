# --description--

A `nav` element holds the links that take a visitor around the site. Inside the `header`, below the `h1`, add a `nav` element. Inside it, add one link to the home page. Set its `href` to `index.html` and give it the text `Home`.

# --hints--

Your `header` element should contain a `nav` element. Its opening tag is `<nav>`.

```js
assert.exists(document.querySelector('header > nav'));
```

Your `nav` element needs a closing tag, `</nav>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/nav\s*>/i);
```

Your `nav` element should come right below the `h1` element, inside the `header`.

```js
assert.strictEqual(document.querySelector('header > h1').nextElementSibling, document.querySelector('header > nav'));
```

Your `nav` element should have one link. A link is an `a` element, and it needs a closing tag, `</a>`.

```js
assert.lengthOf(document.querySelectorAll('nav > a'), 1);
assert.match(code, /<\/a\s*>/i);
```

Your link should have the attribute `href="index.html"`. Put the value in quotation marks inside the opening tag.

```js
assert.equal(document.querySelector('nav > a')?.getAttribute('href'), 'index.html');
```

Your link should have the text `Home`. The text goes between the opening and closing tags.

```js
assert.equal(document.querySelector('nav > a')?.textContent.trim(), 'Home');
```

## --hint--

The `nav` goes inside the `header`, below the `h1`. A link is an `a` element, and its `href` attribute says which file it opens.

The link is `<a href="index.html">Home</a>`. Put it between `<nav>` and `</nav>`.
