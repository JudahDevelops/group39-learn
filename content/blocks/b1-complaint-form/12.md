# --description--

A `table` element shows data in rows and columns. Below the new `h2`, add a `table` element. Inside it, add a `thead` element with one `tr` row of five `th` header cells: `ID`, `Category`, `Urgency`, `Deadline` and `Status`.

# --hints--

Your page should have a `table` element. Its opening tag is `<table>`.

```js
assert.match(code, /<table[\s>]/i);
```

Your `table` element needs a closing tag, `</table>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/table\s*>/i);
```

Your `table` element should come right below the `Your complaints` heading.

```js
assert.strictEqual(document.querySelectorAll('body > h2')[2].nextElementSibling, document.querySelector('body > table'));
```

Your `table` element should have a `thead` element that holds one row, a `tr` element.

```js
assert.exists(document.querySelector('table > thead > tr'));
```

Your `thead` and `tr` elements need closing tags, `</thead>` and `</tr>`.

```js
assert.match(code, /<\/thead\s*>/i);
assert.match(code, /<\/tr\s*>/i);
```

Your header row should have five `th` cells, and each needs a closing tag, `</th>`.

```js
assert.lengthOf(document.querySelectorAll('thead th'), 5);
assert.lengthOf(code.match(/<\/th\s*>/gi) ?? [], 5);
```

Your five `th` cells should have the text `ID`, `Category`, `Urgency`, `Deadline` and `Status`, in that order. Check the spelling.

```js
const heads = [...document.querySelectorAll('thead th')].map((th) => th.textContent.trim());
assert.deepEqual(heads, ['ID', 'Category', 'Urgency', 'Deadline', 'Status']);
```

# --help--

## --hint--

Build a table from the outside in: the table, then a group for the header, then one row, then the cells.

## --hint--

The `table` holds a `thead`. The `thead` holds one `tr`. The `tr` holds five `th` cells, one for each column heading.

## --hint--

Type `<table>`, `<thead>` and `<tr>` on separate lines. Then type `<th>ID</th><th>Category</th><th>Urgency</th><th>Deadline</th><th>Status</th>`. Finish with `</tr>`, `</thead>` and `</table>`, each on its own line.
