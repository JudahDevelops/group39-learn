# --description--

In this workshop you will build the Student Portal, the page where Amina in room B-214 reports a fault in her room.

The page already has its doctype, `head` and `body`. Inside the `body`, add an `h1` element with the text `Student Portal`.

# --hints--

Your `body` element should contain an `h1` element. Its opening tag is `<h1>`.

```js
assert.exists(document.querySelector('body > h1'));
```

Your `h1` element needs a closing tag, `</h1>`, with a `/` just after the `<`.

```js
assert.match(code, /<\/h1\s*>/i);
```

Your `h1` element should have the text `Student Portal`. Check the spelling and the capital letters.

```js
assert.equal(document.querySelector('body > h1')?.textContent.trim(), 'Student Portal');
```

# --help--

## --hint--

An `h1` element is the main heading of a page. Like most elements, it has an opening tag, the text, and a closing tag.

## --hint--

The opening tag is `<h1>` and the closing tag is `</h1>`. The text goes between them, inside the `body`.

## --hint--

Type `<h1>Student Portal</h1>` on the empty line.
