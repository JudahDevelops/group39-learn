# --description--

The warden's app needs a list of rooms. A route connects an address to a function. Add a route for `GET /rooms` with `@app.get("/rooms")` above a function that returns `rooms`.

# --hints--

Your app should answer `GET /rooms` with status 200.

```py
r = await client.get('/rooms')
assert r.status_code == 200
```

`GET /rooms` should return a list.

```py
r = await client.get('/rooms')
assert isinstance(r.json(), list)
```

`GET /rooms` should return all 3 rooms.

```py
r = await client.get('/rooms')
assert len(r.json()) == 3
assert r.json()[0]['number'] == 'A-101'
```

# --solutions--

```python file=main.py
from fastapi import FastAPI

app = FastAPI()

rooms = [
    {"id": 1, "number": "A-101", "beds": 4},
    {"id": 2, "number": "A-102", "beds": 2},
    {"id": 3, "number": "B-214", "beds": 4},
]

@app.get("/rooms")
def list_rooms():
    return rooms
```

# --help--

## --hint--

A decorator is a line that starts with `@` and sits right above a function.

## --hint--

The decorator is `@app.get("/rooms")`. The function under it returns the `rooms` list.

## --hint--

Type `@app.get("/rooms")`, press Enter, then type `def list_rooms():`. On the next line, indent by 4 spaces and write `return rooms`.
