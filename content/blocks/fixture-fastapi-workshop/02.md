# --description--

A student wants one room, not the whole list. Add a route for `GET /rooms/{room_id}` that returns the room with that `id`. When no room has it, answer with status 404 by raising an `HTTPException`, which you import from `fastapi`.

# --hints--

`GET /rooms/2` should return the room `A-102`.

```py
r = await client.get('/rooms/2')
assert r.status_code == 200
assert r.json()['number'] == 'A-102'
```

`GET /rooms/99` should answer with status 404.

```py
r = await client.get('/rooms/99')
assert r.status_code == 404
```

The 404 reply should say `Room not found` in its `detail`.

```py
r = await client.get('/rooms/99')
assert r.json()['detail'] == 'Room not found'
```

`GET /rooms` should still return all 3 rooms.

```py
r = await client.get('/rooms')
assert len(r.json()) == 3
```

# --solutions--

```python file=main.py
from fastapi import FastAPI

app = FastAPI()

rooms = [
    {"id": 1, "number": "A-101", "beds": 4},
    {"id": 2, "number": "A-102", "beds": 2},
    {"id": 3, "number": "B-214", "beds": 4},
]

@app.get("/rooms")
def list_rooms():
    return rooms

from fastapi import HTTPException

@app.get("/rooms/{room_id}")
def get_room(room_id: int):
    for room in rooms:
        if room["id"] == room_id:
            return room
    raise HTTPException(status_code=404, detail="Room not found")
```

## --hint--

The part of the address in curly brackets, `{room_id}`, becomes a function argument with the same name.

## --hint--

Loop over `rooms`. Return the room whose `"id"` equals `room_id`. After the loop, raise `HTTPException(status_code=404, detail="Room not found")`.
