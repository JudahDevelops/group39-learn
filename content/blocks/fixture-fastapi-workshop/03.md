# --description--

Students need to add rooms. Add a pydantic model `RoomIn` with `number` (text) and `beds` (a whole number), and a route for `POST /rooms` that takes it, adds a new room to `rooms` and returns it with status 201. FastAPI answers 422 by itself when the body does not fit the model.

# --hints--

`POST /rooms` with a number and beds should answer with status 201.

```py
r = await client.post('/rooms', json={'number': 'C-301', 'beds': 2})
assert r.status_code == 201
```

The reply should hold the `number` and `beds` that were sent, and an `id`.

```py
r = await client.post('/rooms', json={'number': 'C-302', 'beds': 6})
room = r.json()
assert room['number'] == 'C-302'
assert room['beds'] == 6
assert 'id' in room
```

A room that was added should appear in `GET /rooms`.

```py
before = len((await client.get('/rooms')).json())
await client.post('/rooms', json={'number': 'C-303', 'beds': 4})
after = len((await client.get('/rooms')).json())
assert after == before + 1
```

A body with no `beds`, or with `beds` that is not a number, should be refused with status 422.

```py
missing = await client.post('/rooms', json={'number': 'C-304'})
assert missing.status_code == 422
wrong = await client.post('/rooms', json={'number': 'C-304', 'beds': 'many'})
assert wrong.status_code == 422
```

# --solutions--

```python file=main.py
from fastapi import FastAPI

app = FastAPI()

rooms = [
    {"id": 1, "number": "A-101", "beds": 4},
    {"id": 2, "number": "A-102", "beds": 2},
    {"id": 3, "number": "B-214", "beds": 4},
]

@app.get("/rooms")
def list_rooms():
    return rooms

from fastapi import HTTPException

@app.get("/rooms/{room_id}")
def get_room(room_id: int):
    for room in rooms:
        if room["id"] == room_id:
            return room
    raise HTTPException(status_code=404, detail="Room not found")

from pydantic import BaseModel

class RoomIn(BaseModel):
    number: str
    beds: int

@app.post("/rooms", status_code=201)
def create_room(room: RoomIn):
    new_room = {"id": len(rooms) + 1, "number": room.number, "beds": room.beds}
    rooms.append(new_room)
    return new_room
```

# --help--

## --hint--

A pydantic model is a class that lists the fields a body must have, each with its type. FastAPI checks every body against it.

## --hint--

Import `BaseModel` from `pydantic`, then write `class RoomIn(BaseModel):` with the fields `number: str` and `beds: int`. The route function takes `room: RoomIn` as its argument.

## --hint--

Use `@app.post("/rooms", status_code=201)`. Inside the function, build a dictionary with a new `id` of `len(rooms) + 1`, add it with `rooms.append(...)` and return it.
