# --description--

Add a `body` rule below the `*` rule with three declarations: `font-family` set to `system-ui, sans-serif`, `color` set to `var(--text)` and `margin` set to `0`. Browsers leave a margin of about 8px around the body, and `0` removes it so that the navigation bar can reach the edges of the screen.

# --hints--

Your `body` should have a `font-family` of `system-ui, sans-serif`. Check the spelling and the comma.

```js
const family = getComputedStyle(document.body).fontFamily;
assert.include(family, 'system-ui');
assert.include(family, 'sans-serif');
```

Your `body` should have a `color` of `#1a1a1a`.

```js
assert.equal(getComputedStyle(document.body).color, 'rgb(26, 26, 26)');
```

Your `body` rule should use the variable: `color: var(--text);`.

```js
assert.match(files['css/style.css'], /body\s*\{[^}]*color\s*:\s*var\(\s*--text\s*\)/);
```

Your `body` should have a `margin` of `0` on all four sides.

```js
const cs = getComputedStyle(document.body);
['Top', 'Right', 'Bottom', 'Left'].forEach((side) => assert.equal(cs['margin' + side], '0px'));
```

# --help--

## --hint--

The font and the text colour are properties of the `body`, and every element inside it inherits them. The margin is a space around the `body` itself.

## --hint--

Use `font-family`, `color` and `margin`. For the colour, read the variable with `var()`.

## --hint--

Type `body {`, then `font-family: system-ui, sans-serif;`, `color: var(--text);` and `margin: 0;` on three lines, then `}`.
