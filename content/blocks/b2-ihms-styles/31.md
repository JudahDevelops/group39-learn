# --description--

Most students will use the Student Portal on a phone. A **media query** applies its rules only when its condition is true. At the end of `css/style.css`, add `@media (max-width: 600px)`, which means a screen 600px wide or less. Inside its braces, add a `nav` rule that sets `flex-direction` to `column`, so that the links stack.

# --hints--

Your `css/style.css` should have a media query that starts with `@media (max-width: 600px)`.

```js
const media = [...document.styleSheets].flatMap((s) => [...s.cssRules]).filter((r) => r instanceof CSSMediaRule);
assert.isTrue(media.some((r) => /max-width:\s*600px/.test(r.media.mediaText)));
```

Your media query should have a rule for `nav` inside its curly braces.

```js
const media = [...document.styleSheets].flatMap((s) => [...s.cssRules]).filter((r) => r instanceof CSSMediaRule && /max-width:\s*600px/.test(r.media.mediaText));
assert.isTrue(media.some((r) => [...r.cssRules].some((c) => c.selectorText === 'nav')));
```

The `nav` rule inside your media query should set `flex-direction` to `column`.

```js
const media = [...document.styleSheets].flatMap((s) => [...s.cssRules]).filter((r) => r instanceof CSSMediaRule && /max-width:\s*600px/.test(r.media.mediaText));
const rule = media.flatMap((r) => [...r.cssRules]).find((c) => c.selectorText === 'nav');
assert.exists(rule);
assert.equal(rule.style.flexDirection, 'column');
```

Your `nav` should still be a row on a wide screen. Check that your new rule is inside the media query, not outside it.

```js
assert.equal(getComputedStyle(document.querySelector('nav')).flexDirection, 'row');
```

# --help--

## --hint--

A media query wraps other rules in its own curly braces. The condition goes in brackets after `@media`.

## --hint--

The structure is `@media (max-width: 600px) {`, then a full `nav` rule, then a closing `}` for the media query.

## --hint--

Type `@media (max-width: 600px) {`, then `nav {`, then `flex-direction: column;`, then `}` to close `nav`, then `}` to close the media query.
