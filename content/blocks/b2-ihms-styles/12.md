# --description--

The footer text is secondary, so it should be quieter than the rest. Add a `footer` rule with `color` set to `var(--muted)` and `padding` set to `1rem`.

# --hints--

Your `footer` should have a `color` of `#5b6b80`. Use the variable: `var(--muted)`.

```js
assert.equal(getComputedStyle(document.querySelector('footer')).color, 'rgb(91, 107, 128)');
```

Your `footer` should have a `padding` of `1rem` on all four sides.

```js
const cs = getComputedStyle(document.querySelector('footer'));
['Top', 'Right', 'Bottom', 'Left'].forEach((side) => assert.equal(cs['padding' + side], '16px'));
```

# --help--

## --hint--

The `footer` element holds the paragraph, and the paragraph inherits the text colour from it.

## --hint--

The rule has two declarations: `color` and `padding`.

## --hint--

Type `footer {`, then `color: var(--muted);` and `padding: 1rem;` on two lines, then `}`.
