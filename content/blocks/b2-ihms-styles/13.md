# --description--

The complaint form is the element with the `id` `complaint-form`. In a selector, a hash matches an id. Stack its label, field and button in a column. Add a `#complaint-form` rule with `display` set to `flex`, `flex-direction` set to `column` and `gap` set to `0.5rem`.

# --hints--

Your `css/style.css` should have a rule for `#complaint-form`. The hash matches the `id`.

```js
assert.match(files['css/style.css'], /#complaint-form\s*\{/);
```

Your `#complaint-form` should have a `display` of `flex`.

```js
assert.equal(getComputedStyle(document.querySelector('#complaint-form')).display, 'flex');
```

Your `#complaint-form` should have a `flex-direction` of `column`.

```js
assert.equal(getComputedStyle(document.querySelector('#complaint-form')).flexDirection, 'column');
```

Your `#complaint-form` should have a `gap` of `0.5rem`.

```js
assert.equal(getComputedStyle(document.querySelector('#complaint-form')).rowGap, '8px');
```

Your label, field and button should be stacked, one under another.

```js
const label = document.querySelector('#complaint-form label').getBoundingClientRect();
const field = document.querySelector('#complaint-form textarea').getBoundingClientRect();
const button = document.querySelector('#complaint-form button').getBoundingClientRect();
assert.isAtLeast(field.top, label.bottom - 1);
assert.isAtLeast(button.top, field.bottom - 1);
```

# --help--

## --hint--

The form is the flex container, and its label, field and button are the items. A column stacks the items instead of lining them up in a row.

## --hint--

The rule has three declarations: `display`, `flex-direction` and `gap`.

## --hint--

Type `#complaint-form {`, then `display: flex;`, `flex-direction: column;` and `gap: 0.5rem;` on three lines, then `}`.
