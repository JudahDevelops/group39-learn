# --description--

Make the wrapper scroll. Add a `.table-wrap` rule with `overflow-x` set to `auto`. When the table is wider than the screen, the table scrolls sideways inside its box and the page stays still.

# --hints--

Your `css/style.css` should have a rule for `.table-wrap`.

```js
assert.match(files['css/style.css'], /\.table-wrap\s*\{/);
```

Your `.table-wrap` should have an `overflow-x` of `auto`.

```js
assert.equal(getComputedStyle(document.querySelector('.table-wrap')).overflowX, 'auto');
```

# --help--

## --hint--

`overflow` says what happens to content that does not fit in its box. The `x` means sideways.

## --hint--

The rule has one declaration: `overflow-x`, with the value `auto`.

## --hint--

Type `.table-wrap {`, then `overflow-x: auto;`, then `}`.
