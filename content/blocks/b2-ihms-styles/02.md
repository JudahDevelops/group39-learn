# --description--

The IHMS has a palette of six colours. A **variable** names a value once, so you can reuse it. Variables go in a rule with the selector `:root`, and their names start with two hyphens.

In `css/style.css`, add a `:root` rule with six variables: `--primary` set to `#1f5c99`, `--text` set to `#1a1a1a`, `--muted` set to `#5b6b80`, `--urgent` set to `#b42318`, `--normal` set to `#b45309` and `--low` set to `#2e7d4f`. The last three are for the three urgency levels.

# --hints--

Your `css/style.css` should have a `:root` rule. It starts with `:root {` and ends with `}`.


# --help--

## --hint--

A variable name starts with two hyphens. The value follows a colon, and every declaration ends with a semicolon.

## --hint--

Write `:root {`, then one line for each variable, such as `--primary: #1f5c99;`, then `}`.

## --hint--

Type `:root {`, then the six variables from `--primary: #1f5c99;` to `--low: #2e7d4f;`, one on each line, then `}`.
