# --description--

Make the header row stand out. Add a `th` rule with `background-color` set to `var(--primary)` and `color` set to `white`.

# --hints--

Your `th` cells should have a `background-color` of `#1f5c99`. Use the variable: `var(--primary)`.

```js
const heads = document.querySelectorAll('th');
assert.lengthOf(heads, 5);
heads.forEach((th) => assert.equal(getComputedStyle(th).backgroundColor, 'rgb(31, 92, 153)'));
```

Your `th` cells should have a `color` of `white`.

```js
document.querySelectorAll('th').forEach((th) => assert.equal(getComputedStyle(th).color, 'rgb(255, 255, 255)'));
```
