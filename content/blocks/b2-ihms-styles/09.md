# --description--

Turn the row into a bar. Inside the `nav` rule, below `gap`, add three declarations: `flex-wrap` set to `wrap`, so that links move to a new line when there is no room; `padding` set to `1rem`; and `background-color` set to `var(--primary)`.

# --hints--

Your `nav` should have a `flex-wrap` of `wrap`.

```js
assert.equal(getComputedStyle(document.querySelector('nav')).flexWrap, 'wrap');
```

Your `nav` should have a `padding` of `1rem` on all four sides.

```js
const cs = getComputedStyle(document.querySelector('nav'));
['Top', 'Right', 'Bottom', 'Left'].forEach((side) => assert.equal(cs['padding' + side], '16px'));
```

Your `nav` should have a `background-color` of `#1f5c99`.

```js
assert.equal(getComputedStyle(document.querySelector('nav')).backgroundColor, 'rgb(31, 92, 153)');
```

Your `nav` rule should use the variable: `background-color: var(--primary);`.

```js
assert.match(files['css/style.css'], /nav\s*\{[^}]*background-color\s*:\s*var\(\s*--primary\s*\)/);
```

# --help--

## --hint--

All three declarations go inside the `nav` rule you already have, not in a new rule.

## --hint--

The properties are `flex-wrap`, `padding` and `background-color`. The colour is a variable, so it is written with `var()`.

## --hint--

Type `flex-wrap: wrap;`, `padding: 1rem;` and `background-color: var(--primary);` on three lines below `gap: 1rem;`.
