# --description--

Style the field where students describe the fault. Add a `textarea` rule with `padding` set to `0.5rem`, `border` set to `1px solid var(--muted)` and `border-radius` set to `8px`.

# --hints--

Your `textarea` should have a `padding` of `0.5rem` on all four sides.

```js
const cs = getComputedStyle(document.querySelector('textarea'));
['Top', 'Right', 'Bottom', 'Left'].forEach((side) => assert.equal(cs['padding' + side], '8px'));
```

Your `textarea` should have a border that is `1px` wide and `solid`.

```js
const cs = getComputedStyle(document.querySelector('textarea'));
assert.equal(cs.borderTopWidth, '1px');
assert.equal(cs.borderTopStyle, 'solid');
```

Your `textarea` border should have the colour `#5b6b80`. Use the variable: `var(--muted)`.

```js
assert.equal(getComputedStyle(document.querySelector('textarea')).borderTopColor, 'rgb(91, 107, 128)');
```

Your `textarea` should have a `border-radius` of `8px`.

```js
assert.equal(getComputedStyle(document.querySelector('textarea')).borderTopLeftRadius, '8px');
```

# --help--

## --hint--

This rule has the same kinds of declaration as the form card: padding, a border and rounded corners.

## --hint--

The colour in the border is a variable, so it is written with `var()`.

## --hint--

Type `textarea {`, then `padding: 0.5rem;`, `border: 1px solid var(--muted);` and `border-radius: 8px;` on three lines, then `}`.
