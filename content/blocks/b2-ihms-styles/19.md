# --description--

Shape the button. Inside the `button` rule, below `color`, add `border` set to `none`, which removes the default border, `border-radius` set to `8px` and `padding` set to `0.75rem 1rem`. A roomy button is easier to tap on a phone.

# --hints--

Your `button` should have no border. Set `border` to `none`.

```js
assert.equal(getComputedStyle(document.querySelector('button')).borderTopStyle, 'none');
```

Your `button` should have a `border-radius` of `8px`.

```js
assert.equal(getComputedStyle(document.querySelector('button')).borderTopLeftRadius, '8px');
```

Your `button` should have `0.75rem` of padding above and below, and `1rem` on the left and right.

```js
const cs = getComputedStyle(document.querySelector('button'));
assert.equal(cs.paddingTop, '12px');
assert.equal(cs.paddingBottom, '12px');
assert.equal(cs.paddingLeft, '16px');
assert.equal(cs.paddingRight, '16px');
```
