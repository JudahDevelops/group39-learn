# --description--

The navigation links are inside a `nav` element. Put them in a row. Add a `nav` rule with `display` set to `flex`, which lines up the children of an element in a row, and `gap` set to `1rem`, which is the space between them.

# --hints--

Your `nav` should have a `display` of `flex`.

```js
assert.equal(getComputedStyle(document.querySelector('nav')).display, 'flex');
```

Your `nav` should have a `gap` of `1rem`.

```js
assert.equal(getComputedStyle(document.querySelector('nav')).columnGap, '16px');
```

Your four links should sit in one row.

```js
const tops = [...document.querySelectorAll('nav a')].map((a) => Math.round(a.getBoundingClientRect().top));
assert.lengthOf(tops, 4);
assert.equal(new Set(tops).size, 1);
```

# --help--

## --hint--

Flexbox starts on the parent. The `nav` is the parent, and its links are the flex items.

## --hint--

The rule has two declarations: `display` and `gap`.

## --hint--

Type `nav {`, then `display: flex;` and `gap: 1rem;` on two lines, then `}`.
