# --description--

A comma lets one rule style several selectors. Below the `body` rule, add a rule for `h1, h2` that sets `color` to `var(--primary)`.

# --hints--

Your `h1` should have a `color` of `#1f5c99`.

```js
assert.equal(getComputedStyle(document.querySelector('h1')).color, 'rgb(31, 92, 153)');
```

Every `h2` should have a `color` of `#1f5c99`.

```js
const headings = document.querySelectorAll('h2');
assert.isAbove(headings.length, 0);
headings.forEach((h) => assert.equal(getComputedStyle(h).color, 'rgb(31, 92, 153)'));
```

Your `h1, h2` rule should use the variable: `color: var(--primary);`.

```js
assert.match(files['css/style.css'], /h1\s*,\s*h2\s*\{[^}]*var\(\s*--primary\s*\)/);
```

# --help--

## --hint--

Write the two selectors with a comma between them, then put one declaration in the braces.

## --hint--

The selector is `h1, h2`. The declaration is `color`, a colon, `var()` with the variable name inside, and a semicolon.

## --hint--

Type `h1, h2 {`, then `color: var(--primary);`, then `}`.
