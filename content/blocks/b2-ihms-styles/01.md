# --description--

In this workshop you will style the Student Portal and build the stylesheet that all the IHMS pages share. The page, `student.html`, is already written. The styles go in `css/style.css`, a file called `style.css` inside a folder called `css`. It is empty for now.

First, connect the two. In the `head`, below the `title`, add a `link` element with `rel` set to `stylesheet` and `href` set to `css/style.css`. The `href` is the path to the file: the folder, a `/`, then the file name.

# --hints--

Your `head` element should have a `link` element.

```js
assert.match(code, /<head[\s>][\s\S]*<link[\s>][\s\S]*<\/head\s*>/i);
```

Your `link` element should have the attribute `rel="stylesheet"`. Put the value in quotation marks inside the tag.

```js
assert.match(code, /<link\s[^>]*rel\s*=\s*("|')stylesheet\1[^>]*>/i);
```

Your `link` element should have the attribute `href="css/style.css"`. Check the folder name, the `/` and the file name.

```js
assert.match(code, /<link\s[^>]*href\s*=\s*("|')(?:\.\/)?css\/style\.css\1[^>]*>/i);
```

A `link` element has no closing tag. Remove any `</link>`.

```js
assert.notMatch(code, /<\/link\s*>/i);
```

# --help--

## --hint--

A `link` element connects the page to another file. Like `meta`, it is one tag with attributes and has no closing tag.

## --hint--

Write `<link`, then the attribute `rel="stylesheet"`, then the attribute `href="css/style.css"`, then `>`.

## --hint--

Type `<link rel="stylesheet" href="css/style.css">` on the empty line.
