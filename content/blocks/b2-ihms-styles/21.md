# --description--

`:focus` applies while a field is selected, for example after a click or when a keyboard user reaches it. Add a `textarea:focus` rule that sets `outline` to `2px solid var(--primary)`. Never remove the focus outline without replacing it. Keyboard users need it to see where they are.

# --hints--

Your `css/style.css` should have a rule for `textarea:focus`.

```js
const rules = [...document.styleSheets].flatMap((s) => [...s.cssRules]).filter((r) => r instanceof CSSStyleRule);
assert.isTrue(rules.some((r) => /textarea:focus/.test(r.selectorText)));
```

Your `textarea:focus` rule should set an `outline` that is `2px` wide and `solid`.

```js
const rules = [...document.styleSheets].flatMap((s) => [...s.cssRules]).filter((r) => r instanceof CSSStyleRule);
const rule = rules.find((r) => /textarea:focus/.test(r.selectorText));
assert.exists(rule);
assert.match(rule.style.getPropertyValue('outline'), /2px\s+solid/);
```

Your `textarea:focus` outline should use the colour variable: `var(--primary)`.

```js
const rules = [...document.styleSheets].flatMap((s) => [...s.cssRules]).filter((r) => r instanceof CSSStyleRule);
const rule = rules.find((r) => /textarea:focus/.test(r.selectorText));
assert.exists(rule);
assert.match(rule.style.getPropertyValue('outline'), /var\(\s*--primary\s*\)/);
```

# --help--

## --hint--

The state goes after the selector, joined with a colon and no space.

## --hint--

`outline` takes the same three values as `border`: the width, the style and the colour.

## --hint--

Type `textarea:focus {`, then `outline: 2px solid var(--primary);`, then `}`.
