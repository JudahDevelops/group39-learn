# --description--

On a phone, a wide table can push the whole page sideways. Put the `table` inside a `div` with the class `table-wrap`. A `div` is a plain box with no meaning of its own, so it suits a wrapper. The comment stays above the `div`.

# --hints--

Your page should have one `div` with the class `table-wrap`.

```js
assert.lengthOf(document.querySelectorAll('div.table-wrap'), 1);
```

Your `table` should be inside the `div` with the class `table-wrap`. The `div` needs an opening tag before the `table` and a closing tag after it.

```js
assert.exists(document.querySelector('div.table-wrap > table'));
```

Your `div` should be inside the `main`, and your table should keep its three rows.

```js
assert.exists(document.querySelector('main > div.table-wrap'));
assert.lengthOf(document.querySelectorAll('div.table-wrap tbody tr'), 3);
```

# --help--

## --hint--

The wrapper goes around the whole table, from `<table>` to `</table>`. Think of a box with the table inside.

## --hint--

Put `<div class="table-wrap">` on the line above `<table>` and `</div>` on the line below `</table>`.

## --hint--

Type `<div class="table-wrap">` before the table and `</div>` after it. The indentation does not matter to the browser.
