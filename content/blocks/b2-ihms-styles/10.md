# --description--

Links are blue and underlined by default, which is hard to read on a blue bar. Add a rule for `nav a`, which matches every link inside the `nav`. Set `color` to `white` and `text-decoration`, the underline, to `none`.

# --hints--

Your `css/style.css` should have a rule for `nav a`. A space between the two names means a link inside the `nav`.

```js
assert.match(files['css/style.css'], /nav\s+a\s*\{/);
```

Your links in the `nav` should have a `color` of `white`.

```js
const links = document.querySelectorAll('nav a');
assert.lengthOf(links, 4);
links.forEach((a) => assert.equal(getComputedStyle(a).color, 'rgb(255, 255, 255)'));
```

Your links in the `nav` should have no underline. Set `text-decoration` to `none`.

```js
document.querySelectorAll('nav a').forEach((a) => assert.equal(getComputedStyle(a).textDecorationLine, 'none'));
```
