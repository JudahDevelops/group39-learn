# --description--

Browsers leave a small gap between table cells. Inside the `table` rule, below `width`, add `border-collapse` set to `collapse`. The cells then share one border instead of each drawing its own, so no gaps show.

# --hints--

Your `table` should have a `border-collapse` of `collapse`.

```js
assert.equal(getComputedStyle(document.querySelector('table')).borderCollapse, 'collapse');
```

The cells in your table should touch, with no gap between them. Check that `border-collapse` is inside the `table` rule.

```js
const cells = [...document.querySelectorAll('thead th')].map((th) => th.getBoundingClientRect());
assert.isAbove(cells.length, 1);
assert.approximately(cells[1].left, cells[0].right, 0.5);
```

# --help--

## --hint--

How cell borders are drawn is a property of the whole `table`, not of its cells.

## --hint--

The property is `border-collapse` and the value is `collapse`. Add it inside the `table` rule you already have.

## --hint--

Type `border-collapse: collapse;` on the empty line below `width: 100%;`.
