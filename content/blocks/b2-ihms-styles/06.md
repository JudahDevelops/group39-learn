# --description--

Paragraphs are easier to read with more space between the lines. Add a `p` rule that sets `line-height` to `1.5`. That is one and a half times the font size.

# --hints--

Your `css/style.css` should have a rule for `p`.

```js
assert.match(files['css/style.css'], /(^|[\s}])p\s*\{/);
```

Every `p` should have a `line-height` of `1.5`. Write the number with no unit.

```js
const paragraphs = document.querySelectorAll('p');
assert.isAbove(paragraphs.length, 0);
paragraphs.forEach((p) => {
  const cs = getComputedStyle(p);
  assert.approximately(parseFloat(cs.lineHeight), parseFloat(cs.fontSize) * 1.5, 0.1);
});
```

# --help--

## --hint--

`line-height` is a number that is multiplied by the font size. It needs no unit.

## --hint--

The selector is `p`, which matches every paragraph. The declaration is `line-height` and the value `1.5`.

## --hint--

Type `p {`, then `line-height: 1.5;`, then `}`.
