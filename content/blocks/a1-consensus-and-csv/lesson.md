**Consensus** (consensus.app) is a search engine for academic papers. You type a question and it returns real published papers, with a one-line takeaway from each.

Unlike a chat assistant, every result links to a paper that exists. The group still checked every one (Lesson 1.6).

# --screen-- concept

What is in a CSV row. The columns that identify and summarise a paper:

| Column | Use |
|---|---|
| `Title`, `Authors`, `Year`, `Journal` | Identify the paper |
| `Takeaway` | Consensus's one-line summary: a starting point, not a source |
| `Abstract` | The authors' own summary. Read this. |

# --screen-- concept

The columns that help you judge a paper and check it:

| Column | Use |
|---|---|
| `Citations`, `Journal SJR Quartile` | How often it's cited and how highly the journal is ranked: signals, not proof |
| `Study Type` | Kind of study |
| `DOI` | The paper's permanent ID, used to verify it |
| `Consensus Link` | Back to the paper on Consensus |
